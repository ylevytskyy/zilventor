# Spec — M2.1 Per-Panel Manufacturing DXF

**Date:** 2026-06-23
**Milestone:** M2 — Manufacturing output ("ABF-plugin parity"). Roadmap: `docs/superpowers/plans/2026-06-20-inventor-parity-roadmap.md`.
**Slice:** M2.1 (first of three: M2.1 per-panel mfg DXF → M2.2 nesting DXF → M2.3 shop labels).
**Status:** Design APPROVED in conversation (6 AskUserQuestion rounds, all "Recommended" accepted). This doc reproduces the approved design + conventions confirmed against source. Conventions verified this session via Explore subagent (confidence 92).

## Goal

Export a **machining-ready DXF per unique panel** (CNC/beam-saw/CNC-router shop floor consumption), bundled into a zip. Each DXF carries the panel outline, all bores (layered by face + diameter), grooves, edge-band edges, grain arrow, an info text block, and native L/W DIMENSION entities — all in a swappable, configurable layer scheme. This is the generic per-panel output; machine-specific posts are deferred to M3.

Success = a furniture-tab "Export Manufacturing DXF" button produces a zip of `item-<n>-<partName>.dxf` files that, when parsed, contain the expected layers and entity counts for each panel's geometry + machining.

## Locked decisions

1. **Per-panel manufacturing DXF first** (this slice); nesting DXF (M2.2) and labels (M2.3) are separate later slices.
2. **Generic configurable layer scheme** — layer names centralized in one config object so they are swappable; machine-specific posts are M3, not here.
3. **Bores = one CIRCLE per bore, layer per diameter**; grooves = closed LWPOLYLINE rect on a GROOVES layer.
4. **DXF contents = ALL of:** outline + bores + grooves + edge-band edges + grain arrow + title/info text block + native L/W DIMENSION entities + per-bore depth label text.
5. **Bore faces = layer per face** (front / back / edge); back-face bores mirrored into the front-viewing frame.
6. **File granularity = one DXF per unique panel → zip** (via existing `buildDxfZip`).

## Confirmed conventions (verified against source — do NOT re-guess)

Types (`packages/shared/src/`):
- `PanelEdgeKey` = `'front' | 'back' | 'left' | 'right'` — edge-band keys (panel-feature.ts:5).
- `GrainDirection` = `'length' | 'width' | 'none'` (panel-feature.ts:6). `'length'` (default/none) → grain runs along **+X (L)**; `'width'` → grain runs along **+Y (W)**.
- `EdgeBand` = `{ materialId, thickness }`; `PanelSpec` = `{ length, width, thickness, materialId, grain, edgeBands }`; `resolvePanelSpecFromFeature → PanelSpec | null`.
- `BoreOp` (bore.ts:22-40) = `{ id, face: FaceName, u, v, diameter, depth: number | 'throughAll', role, ... }`. `u/v` are in the **panel-local 2D frame of that face** (per-face origin/axes in `face2DFrame`, bore.ts:84-104).
- `FaceName` = `'Top' | 'Bottom' | 'Front' | 'Back' | 'Left' | 'Right'` (bore.ts:43).
- `GrooveFeature` (groove.ts:15-33) = `{ kind:'groove', id, faceRole, axis:'u'|'v', position, width, depth, label? }`. axis='u' → groove runs along that face's uDir; axis='v' → along vDir; `position`/`width` measured perpendicular.

**FaceName → manufacturing-face mapping (CRITICAL — the design intent):** a cut panel laid flat is an L×W rectangle of thickness T. Its two large faces are `Top` (+Z) and `Bottom` (−Z); the four thin faces (`Front`/`Back`/`Left`/`Right`) are the edges.
- `Top` → **front** face bores → layer `BORES-FRONT-<dia>MM`.
- `Bottom` → **back** face bores → layer `BORES-BACK-<dia>MM`, mirrored into the front-viewing frame.
- `Front`/`Back`/`Left`/`Right` → **edge** bores → layer `BORES-EDGE-<edge>-<dia>MM`.

Existing precedent (`packages/app/src/drawing/renderBoringDxf.ts`): origin bottom-left, **L→+X, W→+Y**, outline rectangle `[0,0]–[L,W]`, bore circles drawn at `(u, v)`, depth encoded in layer name (`D{dia}_T{depth}`). It lays multiple panels left-to-right with a gap and does NOT separate by face or mirror — the new builder extends the *pattern* but is a NEW function.

## Approved design — 3 units, all reuse existing seams

### Unit 1 — `renderPanelManufacturingDxf(input: PanelManufacturingInput): string`
NEW pure builder in `packages/app/src/drawing/renderPanelManufacturingDxf.ts`, parallel to `renderBoringDxf`. Uses `createDxfDocument()` from `packages/app/src/drawing/dxfWriter.ts` (`DxfDocument` has `line/circle/arc/lwpolyline/text/polyline/ellipse/spline/block/dimension`, layer string first arg; `hexToAci(hex)` for colors). Pure ⇒ unit-testable on DXF text.

**Coord frame:** L→+X, W→+Y, origin bottom-left, mm, 1:1 (one panel per file, no left-to-right offset).

**Layers** (names centralized in a `MANUFACTURING_LAYERS` config object so they are swappable):
- `OUTLINE` — closed LWPOLYLINE `[0,0]–[L,0]–[L,W]–[0,W]`.
- `BORES-FRONT-<dia>MM` / `BORES-BACK-<dia>MM` / `BORES-EDGE-<edge>-<dia>MM` — one CIRCLE per bore (radius dia/2). Back-face (`Bottom`) bores mirrored into the front frame (see Open item O1 for the exact mirror axis).
- `GROOVES` — closed LWPOLYLINE rectangle per groove (from axis/position/width spanning the face extent).
- `EDGEBAND` — one LINE per banded edge (front/back/left/right edge of the rectangle that has a band).
- `GRAIN` — arrow along the grain axis (+X for 'length', +Y for 'width'); `'none'` ⇒ omit.
- `INFO` — TEXT block: item#, material name, `L×W×T`, qty.
- `DIMENSIONS` — native DIMENSION entities for L (horizontal) and W (vertical).
- `BORE-INFO` — TEXT depth label per bore (e.g. `Ø5×12`, `Ø5 THRU`).

### Unit 2 — `aggregatePanelManufacturing(...): PanelManufacturingInput[]`
NEW gather seam in `packages/app/src/assembly/walkers/` (or `drawing/`) that **combines existing walkers — NO new tree-walk**:
- `aggregateCutListRecursive` → `CutListResult.rows: CutListRow[]` (rowKey, itemNumber, qty, length, width, thickness, materialId, materialName, grain, edgeBands{front,back,left,right}, partPath, partName, componentPathKeys).
- `aggregateBoresRecursive` → `BoringAggregateResult { panels: BoringPanelGroup[] }` (bores per panel, fed from `partBoresCacheRef`/`PartDocument.bores` + `resolvePanelSpec`).
- Groove extraction from `PartDocument.featureTree` entries with `kind:'groove'`.

Returns `PanelManufacturingInput[]`, each `{ itemNumber, partName, spec: PanelSpec, materialName, bores: BoreOp[], grooves: GrooveFeature[], qty }`.

**File-uniqueness key = machining signature** (geometry `L×W×T×material×grain` + sorted bores + grooves), NOT the cut-list geometry-only dedup key. **Same-size panels with different boring/grooves are DIFFERENT files.** `itemNumber` reused from the cut list. Filenames `item-<n>-<partName>.dxf`.

### Unit 3 — `ExportPanelManufacturingDxfCommand` (app/commands)
Gather (Unit 2) → build each (Unit 1) → `buildDxfZip(entries)` (`packages/app/src/drawing/dxfZip.ts`, fflate sync) → trigger download. New button in `packages/app/src/shell/tabs/FurnitureTab.tsx` manufacturing area beside the existing boring/nest/cut-list/export buttons. i18n strings en/uk.

## Chosen defaults (correctable)
- (a) Bore depth shown as **TEXT label** on `BORE-INFO` (not encoded into the layer-name suffix). Front/back/edge separation lives in the layer name; diameter lives in the layer name; depth is text.
- (b) Back-face mirror — **RESOLVED** against `face2DFrame`: a `Bottom`-face bore at `(u, v)` maps into the flat front frame at `(u, W − v)`. The mirror is on **Y** (`Y′ = W − v`), NOT the provisional `X′ = L − u` (that guess was wrong). Derivation: `Bottom` frame origin `(−L/2, +W/2, 0)`, `uDir +X`, `vDir −Y` ⇒ world `(−L/2 + u, W/2 − v, 0)` ⇒ flat-frame `(u, W − v)`.

## Resolved geometry (derived from `face2DFrame`, bore.ts:84-104 — was Open items, now locked)
Per-face frames (origin / uDir / vDir): `Top`(−L/2,−W/2,T)/+X/+Y · `Bottom`(−L/2,+W/2,0)/+X/−Y · `Front`(−L/2,+W/2,0)/+Z/+X · `Back`(+L/2,−W/2,0)/+Z/−X · `Left`(−L/2,−W/2,0)/+Z/+Y · `Right`(+L/2,+W/2,0)/+Z/−Y.
- **O1 — back-face mirror:** `Bottom` bore `(u,v)` → flat `(u, W − v)`. (See default (b).)
- **O2 — edge-bore projection** (uDir=+Z=depth into thickness, vDir=along edge): `Front` → top edge, flat `X = v`, `Y = W`; `Back` → bottom edge, flat `X = L − v`, `Y = 0`; `Left` → left edge, flat `X = 0`, `Y = v`; `Right` → right edge, flat `X = L`, `Y = W − v`. Draw the edge bore CIRCLE centered on the edge at that point (the bore axis lies in-plane; the circle marks edge position + diameter; depth `u` shown in `BORE-INFO`).
- **O3 — groove rectangle math:** groove on `Top`/`Bottom` face. For a `Top` groove, axis='u' runs along +X at cross-offset `v0 = position` (LWPOLYLINE `[0,v0]–[L,v0]–[L,v0+width]–[0,v0+width]`); axis='v' runs along +Y at cross-offset `u0 = position` (`[u0,0]–[u0,0]`... spanning W). For `Bottom` apply the same Y-mirror as bores.
- **O4 — grain axis** confirmed (`length`→+X, `width`→+Y); arrow on `GRAIN` layer along that axis, `'none'` ⇒ omit.
