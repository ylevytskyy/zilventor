# Drawings

> The 2D documentation toolset: turn a part or assembly model into dimensioned, annotated
> sheets you can export as DXF, PDF, PNG, or SVG.

A **Drawing** is its own document kind (file extension `.zidw`) — a set of one or more sheets
holding 2D views projected live from a part or assembly model. You save and open `.zidw`
drawings the same way as any other document, from the **File** tab's Save/Open.

## The general workflow

1. **Open (or create) a drawing document.** Once a `.zidw` document is active, the ribbon's
   top-level tabs are just `File`, `Drawing`, and `View` — the `Drawing` tab is where
   everything below happens, and it expands into 7 panels: **Sheet**, **Place Views**,
   **Dimension**, **Annotate**, **Reference**, **Templates**, **Export**.
2. **Place views** of the source part/assembly onto a sheet (base, projected, iso, section, or
   detail views).
3. **Dimension and annotate** the views — linear/radial/angular dimensions, leader text, center
   marks, balloons, hole tables, parts lists.
4. **Export** the finished sheet(s) to DXF, PDF, PNG, or SVG.

Views are **live projections**, not static pictures — if the source part or assembly changes,
a view can go stale and needs to be brought up to date (see
[Base and Projected Views](./base-and-projected-views.md) for how that works).

## Domain vocabulary

- **Sheet** — one page of a drawing document. A drawing can hold multiple sheets; each sheet
  holds its own set of views, dimensions, and annotations.
- **Base View** — the first view of a part/assembly placed on a sheet, at a chosen orientation
  (front, top, right, etc.) and scale. Every other view type on that sheet derives from a base
  view.
- **Projected View** — a view generated by projecting off an existing view (top/bottom/left/
  right), staying aligned with its parent.
- **Stale view** — a view whose source model has changed since it was last projected. A stale
  view shows a small warning badge in the canvas; it needs to be regenerated (manually or
  automatically) to reflect the current model.
- **Template** — a saved sheet layout (`.zitpl` file) you can reuse to start a new sheet
  without rebuilding it from scratch.
