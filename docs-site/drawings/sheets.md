# Sheets
> Adds a new page to a drawing document that you can place views, dimensions, and annotations
> onto.

**Where:** Drawing ▸ Sheet ▸ **New Sheet** · **Shortcut:** — · **Applies to:** drawing

## What it does

A drawing document can hold more than one sheet. **New Sheet** adds an empty sheet to the
current drawing so you can start placing views on it. The **Sheet…** button in the same panel
is meant to open per-sheet settings (paper size, title block, and similar), but it is not
implemented yet.

## Before you start

- Have a drawing (`.zidw`) document open.

## Steps

1. Click **New Sheet** in the Drawing ▸ Sheet ribbon panel.

*Result: a new, empty sheet is added to the drawing.*

## Options

| Field | Meaning |
|---|---|
| — | New Sheet has no dialog — it adds a sheet immediately. |

## Tips & gotchas

- **Sheet…** (sheet settings/properties) is currently disabled in the ribbon — its tooltip
  reads "Coming in follow-up F1". Don't expect a working dialog behind it yet.
- You don't have to start a sheet empty: the **Templates** panel's **New from Template…**
  button lets you add a sheet pre-built from a saved layout instead of a blank one. See
  [Templates](./templates.md) for the full save/reuse workflow.
