# Двері
> Генерує одні або двоє дверей за розміром отвору шафи, з накладкою, стороною петель і
> стилем — а для суцільних дверей ще й відповідні свердління чашок і пластин петель.

**Де:** Меблі ▸ Присадка ▸ **Двері** · **Гарячі клавіші:** — · **Застосовується до:** збірка (одна шафа)

## Що це робить

Двері будують одні двері або пару дверей за розміром отвору вибраної шафи. Задайте накладку,
сторону петель, товщину, зазор і зазор вкладної, а також оберіть **Стиль** — Суцільні,
Філенчасті (шейкер) або Філенка з фаскою. Для **Суцільних** дверей `AddDoorCommand` також
записує свердління чашок петель на двері та свердління пластин петель на панель шафи зі
стороною петель — усе в межах однієї операції зі скасуванням.

## Перед початком

- Матиме відкритою збірку з уже розміщеною шафою. Кнопка **Двері** неактивна — підказка
  *«Спочатку відкрийте або створіть збірку»* — поки не існує збірка.

## Кроки

1. Натисніть **Двері** на панелі стрічки Меблі ▸ Присадка — це активує курсор вибору одного
   компонента.
2. Клацніть шафу, до якої потрібно додати двері, у 3D-вікні.
3. Відкриється діалог **Додати двері**. Задайте Кількість, Накладку, Сторону петель, Стиль та
   інші поля.
4. Натисніть **OK**.

*Результат: створюються та розміщуються в отворі шафи деталі дверей; для Суцільних дверей на
дверях з'являються свердління чашок петель, а на панелі шафи зі стороною петель — свердління
пластин петель.*

## Параметри

| Поле | Значення |
|---|---|
| Кількість | Одинарні / Подвійні. За замовчуванням Одинарні. |
| Сторона петель | Ліворуч / Праворуч. За замовчуванням Ліворуч. Неактивне, коли Кількість —
Подвійні (подвійні двері автоматично навішуються на обидва зовнішні краї). |
| Накладка | Повна / Напівнакладна / Вкладна. За замовчуванням Повна. |
| Стиль | **Суцільні**, **Філенчасті (шейкер)** або **Філенка з фаскою**. За замовчуванням
Суцільні. Окремої опції «рамкові» немає — Філенчасті (шейкер) і Філенка з фаскою є двома
рамковими конструкціями; Суцільні — це одна плоска панель. |
| Ширина рамки (мм) | Ширина стояка/поперечки для рамкових стилів. За замовчуванням 70 мм.
Неактивне, коли Стиль — Суцільні. |
| Товщина (мм) | Товщина дверей. За замовчуванням 18 мм. |
| Зазор (мм) | Проміжок навколо зовнішнього краю дверей. За замовчуванням 2 мм. |
| Зазор вкладної (мм) | Робочий зазор. За замовчуванням 2 мм. |
| Центральний зазор (мм) | Проміжок між двома дверима подвійного комплекту. За замовчуванням
3 мм. Актуально лише коли Кількість — Подвійні. |
| Петлі (авто) | Лише для читання — кількість петель обчислюється за висотою дверей. Не
редагується користувачем. |
| Пресет обробки (чашка петлі) | Необов'язковий вибір, показується лише якщо в збірці є
пресети обробки для чашок петель. |
| Пресет обробки (пластина петлі) | Необов'язковий вибір, показується лише якщо в збірці є
пресети обробки для пластин петель. |

## Поради та нюанси

- **Стиль має рівно три варіанти** — Суцільні, Філенчасті (шейкер), Філенка з фаскою — а не
  чотири. Якщо потрібні звичайні рамкові двері без піднятої центральної панелі, це саме
  **Філенчасті (шейкер)**; окремого варіанта «Рамкові» немає.
- **Свердління чашок і пластин петель генерується лише для Суцільних дверей.** Рамкові двері
  (Філенчасті (шейкер), Філенка з фаскою) відкладають свердління петель — чашки мають
  розташовуватися в стояку, а це ще не реалізовано — тож перемикання дверей на Філенчасті
  (шейкер) або Філенку з фаскою після генерації не додасть свердління петель автоматично.
- «Петлі (авто)» неможливо перевизначити в цьому діалозі; це суто інформаційне значення.
