# Секції шухляд
> Будує секцію з 2–10 ящиків шухляд по всьому отвору шафи, з боковими напрямними або нижніми
> напрямними Tandem, і вирізає відповідні свердління під напрямні.

**Де:** Меблі ▸ Присадка ▸ **Шухляди** · **Гарячі клавіші:** — · **Застосовується до:** збірка
(одна шафа)

## Що це робить

Шухляди будують стос деталей ящиків шухляд за розміром отвору вибраної шафи, рівномірно
розподіляючи висоту отвору між кількістю шухляд (з можливістю редагування для кожної), і
вирізає свердління під напрямні для обраної системи напрямних як у боках шафи, так і в
ящиках шухляд — `AddDrawerBankCommand` виконує створення ящиків і присадку як один крок зі
скасуванням.

## Перед початком

- Матиме відкритою збірку з уже розміщеною шафою. Кнопка **Шухляди** неактивна — підказка
  *«Спочатку відкрийте або створіть збірку»* — поки не існує збірка.

## Кроки

1. Натисніть **Шухляди** на панелі стрічки Меблі ▸ Присадка — це активує курсор вибору одного
   компонента.
2. Клацніть шафу, до якої потрібно додати шухляди, у 3D-вікні. Діалог зчитує ширину і висоту
   отвору шафи з цього вибору.
3. Відкриється діалог **Додати секцію шухляд** із висотами шухляд, попередньо рівномірно
   розподіленими по отвору. Задайте Кількість, Накладку, Товщину, Систему напрямних та за
   потреби відкоригуйте висоти окремих шухляд.
4. Натисніть **OK**.

*Результат: деталі ящиків шухляд розміщуються в шафі, а свердління під напрямні вирізаються в
боках шафи та ящиках шухляд (бокові напрямні) або в днищах/задніх стінках шухляд і боках шафи
(Tandem).*

## Параметри

| Поле | Значення |
|---|---|
| Кількість | Кількість шухляд, 2–10. За замовчуванням 3. |
| Накладка | Повна / Напівнакладна / Вкладна. За замовчуванням Повна. |
| Товщина (мм) | Товщина матеріалу ящика шухляди. За замовчуванням 18 мм. |
| Система напрямних | **Бокові напрямні** або **Tandem (нижнє кріплення)**. За замовчуванням
Бокові напрямні. |
| Пресет обробки — корпус | Необов'язково, показується лише для Tandem, якщо є відповідні
пресети. |
| Пресет обробки — шухляда | Необов'язково, показується лише для Tandem, якщо є відповідні
пресети. |
| Висоти шухляд (мм) | По одному рядку на шухляду, попередньо заповнено рівномірним поділом
висоти отвору (залишок додається до останньої шухляди); редагується. Рядок «Залишок: N мм»
має показувати 0, перш ніж стане доступним OK. |

## Поради та нюанси

- Висоти мають сумарно точно (з точністю до 0,5 мм) відповідати висоті отвору шафи — OK
  залишається неактивним, доки «Залишок» не покаже 0 мм.
- Власна назва діалогу для варіанта з нижнім кріпленням — **«Tandem (нижнє кріплення)»**;
  внутрішньо це генерує рядок специфікації з'єднувачів **«Напрямна TANDEM»** (номінальна
  геометрія Blum TANDEM 560H) — див.
  [Специфікація матеріалів](../assemblies/bill-of-materials.md).
- Бокові напрямні та Tandem свердлять **різні грані**: бокові напрямні вирізають внутрішні
  грані боків шафи та боки ящика шухляди; Tandem вирізає днище/задню стінку ящика шухляди і
  боки шафи. Перемикання систем напрямних після генерації змінює розташування свердлінь.
