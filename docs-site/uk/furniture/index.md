# Меблі

> Робочий процес меблевого виробництва: згенеруйте корпус шафи в збірці, потім додайте двері,
> шухляди, лицьові рамки та фурнітуру, і виконайте механічну обробку для виробництва.

Вкладка стрічки **Меблі** — це місце, де поетапно, панель за панеллю, будується збірка шафи.
Схема одна й та сама для всієї вкладки: шаблон **Шафи** генерує багатопанельний корпус (боки,
верх, низ, задня стінка, цоколь, полиці) в активній збірці, а кожен наступний інструмент —
двері, секції шухляд, лицьові рамки, фурнітура, розкрій, статистика — працює з цією збіркою та
панелями всередині неї.

## Загальна схема

1. **Спочатку відкрийте або створіть збірку.** Майже всі кнопки на цій вкладці неактивні (сірі,
   з підказкою *«Спочатку відкрийте або створіть збірку»*), поки не існує `activeAssembly`.
   Єдиний виняток — **Панель** (див. [Панелі](./panels.md)), яка також працює з порожньою
   активною деталлю.
2. **Згенеруйте шафу.** Оберіть один із чотирьох шаблонів у розділі [Шафи](./cabinets.md) —
   Нижня шафа, Кутова шафа, Глухий кутовий корпус або Діагональний кутовий корпус. Кожен
   відкриває власний діалог і після натискання **OK** додає в збірку повний набір панелей.
   Кожна створена так панель отримує мітку `role` (leftSide, rightSide, top, bottom, back,
   toekick, shelf, …) — саме за цією міткою наступні інструменти (присадка корпусу, розкрій,
   специфікація) визначають призначення кожної панелі, не вимагаючи повторного введення цієї
   інформації.
3. **Додайте двері, шухляди та лицьові рамки.** Ці інструменти розташовані на панелі стрічки
   **Присадка** — [Двері](./doors.md), [Шухляди](./drawer-banks.md) та
   [Лицьові рамки](./face-frames.md) — усі вони вимагають клацнути шафу у 3D-вікні перед
   відкриттям діалогу, оскільки розраховують власні розміри за отвором цієї шафи.
4. **Додайте фурнітуру.** [Фурнітура](./hardware.md) дозволяє додати артикул із вбудованого
   каталогу (або з імпортованого власного) до збірки та її специфікації матеріалів.
5. **Виконайте механічну обробку.** Решта панелі Присадка — присадка стикових з'єднань
   корпусу, полицетримачі Система-32, пази, замкові пази, шип/гніздо — описана в окремому
   розділі, оскільки застосовується до будь-якої панелі, а не лише до згенерованих
   інструментами меблів. Див. [Свердління / Присадка](../drilling-prisadka/index.md).
6. **Перегляньте розкрій, вартість і виробничі дані.** [Розкрій](./cut-list.md) та
   [Вартість і статистика](./cost-and-statistics.md) підсумовують усе вищезазначене; розкладка,
   маркування та експорт пакувальних листів розташовані в іншому розділі —
   [Виробництво](../manufacturing/index.md) — вони використовують ту саму вкладку стрічки
   Меблі в застосунку (панелі стрічки **Розкладка** та **Виробництво**), просто документовані
   тут окремо.

## Сторінки цього розділу

| Сторінка | Що охоплює |
|---|---|
| [Панелі](./panels.md) | Довільна панель із листового матеріалу — розміри, матеріал, кромкування |
| [Шафи](./cabinets.md) | Чотири шаблони шаф: Нижня, Кутова, Глухий кутовий корпус, Діагональний кутовий корпус |
| [Двері](./doors.md) | Суцільні/філенчасті (шейкер)/двері з філенкою з фаскою за розміром отвору шафи, зі свердлінням під петлі |
| [Секції шухляд](./drawer-banks.md) | Ящики шухляд із боковими напрямними або нижніми напрямними Tandem |
| [Лицьові рамки](./face-frames.md) | Сітки лицьових рамок Р×С зі стиковими з'єднаннями |
| [Фурнітура](./hardware.md) | Вбудований і власний каталог фурнітури, що додається до специфікації |
| [Розкрій](./cut-list.md) | Розкрій панелей, перенумерація та експорт CSV |
| [Вартість і статистика](./cost-and-statistics.md) | Прайсований звіт із 5 категорій, експорт CSV/XLSX |
