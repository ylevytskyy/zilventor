# Розміщення компонентів
> Вставляйте деталі, підзбірки або STEP-імпорти в збірку, а потім позиціонуйте, закріплюйте або видаляйте їх.

**Де:** вкладка збірки ▸ група Компонент ▸ Розмістити · **Гарячі клавіші:** P (активна лише
коли відкрито документ збірки) · **Застосовується до:** збірки.

## Що це робить

Група Компонент — це спосіб побудувати збірку з елементів, які вже існують у сховищі проєкту
(деталей і підзбірок) або із зовнішнього файлу STEP. **Розмістити** вставляє збережений файл
`.zipt`/`.ziasm` як новий компонент у початок координат збірки. **Вставити зі STEP…** імпортує
файл STEP безпосередньо, створюючи одну нову деталь на кожне тіло, яке він містить. Коли
компонент вже існує, ви можете перемістити або перефарбувати його командою **Редагувати**,
видалити командою **Видалити** або закріпити його для розв'язувача залежностей. Вкладення
підзбірок в інші збірки повністю підтримується — компонент-збірка поводиться як будь-який
інший компонент щодо вибору, редагування та закріплення.

## Перш ніж почати

- Має бути відкрито документ збірки — інакше всі дії в цій групі вимкнено, а комбінація
  клавіш **P** для Розмістити нічого не робить.
- Щоб розмістити збережену деталь або підзбірку, вона має вже існувати у сховищі проєкту **і**
  мати мініатюру — файли без неї непомітно пропускаються в сітці Розмістити компонент (див.
  Поради та підводні камені).
- Щоб скористатися Редагувати, Видалити або Закріпити/Розкріпити, спочатку виберіть цільовий
  компонент — Редагувати й Видалити залишаються вимкненими без вибору, а
  Закріпити/Розкріпити не діють на порожній вибір.

## Кроки

### Розмістити збережену деталь або підзбірку

1. Натисніть **Розмістити** (або клавішу **P**). Відкриється діалог «Розмістити компонент», що
   показує сітку мініатюр із 4 стовпців — по одній на кожен файл `.zipt`/`.ziasm` у сховищі
   проєкту.
2. Клацніть плитку, щоб вибрати її.
3. Натисніть **Розмістити**. Компонент буде вставлено в початок координат збірки.

*Результат: новий компонент з'являється у 3D-вікні перегляду та як рядок у дереві Браузера.*

### Вставити файл STEP

1. Натисніть **Вставити зі STEP…**.
2. У провіднику файлів виберіть файл `.step`/`.stp` або `.zip`, що містить один.
3. Підтвердіть. Однотільний файл STEP стає рівно одним новим компонентом; багатотільний файл
   STEP стає одним новим компонентом на кожне підтіло, кожне з яких реєструється у сховищі
   проєкту та розміщується в початку координат збірки.

*Результат: новий(і) компонент(и) з'являється(ються) у вікні перегляду та в дереві Браузера. У
разі помилки в рядку стану з'являється напис «Помилка вставлення зі STEP: {error}», і нічого
не додається.*

### Редагувати позицію, обертання або колір компонента

1. Виберіть компонент у вікні перегляду або в дереві Браузера.
2. Натисніть **Редагувати**. Відкриється діалог «Редагувати компонент».
3. Налаштуйте потрібні поля (див. Параметри нижче), потім підтвердіть.

*Результат: компонент оновлюється на місці; зміну можна скасувати.*

### Видалити компонент

1. Виберіть компонент.
2. Натисніть **Видалити**.

*Результат: компонент видаляється зі збірки; скасування відновлює точні попередні дані
екземпляра.*

### Закріпити або розкріпити компонент

1. Виберіть компонент верхнього рівня.
2. Натисніть **G**.

*Результат: закріплений компонент показує префікс-ланцюжок (⛓) у дереві Браузера і
розглядається розв'язувачем залежностей як нерухомий якір, вилучений з підрахунку ступенів
свободи. Натисніть **G** ще раз, щоб розкріпити.*

## Параметри

Поля в діалозі «Редагувати компонент»:

| Поле | Значення |
|---|---|
| Позиція (мм) — X / Y / Z | Числові поля зміщення початку координат компонента всередині збірки. |
| Обертання (°) — RX / RY / RZ | Числові поля обертання компонента навколо кожної осі. |
| видимий | Прапорець — приховує або показує компонент у вікні перегляду без видалення. |
| Підзбірка (N компонентів) | Довідковий напис, що показується лише коли вибрано підзбірку; повідомляє, скільки компонентів вона містить. |
| Гнучкий | Прапорець, що показується лише для вибраних підзбірок. Якщо позначено, власні внутрішні залежності підзбірки розв'язуються незалежно, а не «заморожуються» в розміщеній позі. |
| Колір | Вибір кольору зі спільної палітри кольорів збірки. |

## Поради та підводні камені

- Збережена деталь або підзбірка без мініатюри непомітно пропускається в сітці Розмістити
  компонент — жодної помилки не показується. Якщо файл, який ви очікуєте побачити, відсутній,
  перевірте, чи має він збережену мініатюру.
- Подвійне клацання на рядку компонента верхнього рівня в дереві Браузера також відкриває
  діалог Редагувати компонент — не обов'язково спершу вибирати його й натискати
  **Редагувати**.
- Клацання правою кнопкою на рядку компонента-підзбірки в дереві Браузера пропонує відкрити
  базову збірку окремо — для застарілих шаф, яким це потрібно, це включає однокликове
  відновлення пози перед відкриттям.
- Клацання правою кнопкою на рядку компонента-кінцевої деталі дозволяє замінити її колір або
  ввести буквально слово «convert», щоб перетворити імпортовану деталь STEP на параметричну
  панель — див. [Перетворення на панель](../import-migration/convert-to-panel.md).
- Для закріплення немає кнопки на стрічці — це доступно лише з клавіатури (**G**), і працює
  лише поки відкрита збірка.
