# Відомість матеріалів
> Кожна кінцева деталь у дереві збірки, згорнута в одну плоску таблицю з автоматичним підрахунком кількості.

**Де:** вкладка збірки ▸ група ВМ ▸ ВМ · **Гарячі клавіші:** немає · **Застосовується до:**
збірки

## Що це робить

Кнопка стрічки **ВМ** перемикає смужку вкладок лівої панелі Браузера на її вкладку ВМ. Панель
Браузера містить кілька сусідніх вкладок — Збірка / ВМ / Розкрій / Розкладка / Статистика /
Виробництво — і ВМ є однією з них; див. [Розкрій](../furniture/cut-list.md),
[Розкладку](../manufacturing/nesting.md), [Статистику](../furniture/cost-and-statistics.md) та
[Виробництво](../manufacturing/production-reconciliation.md) щодо інших.

ВМ рекурсивно обходить усе дерево компонентів, заглиблюючись у кожну вкладену підзбірку.
Кінцеві деталі групуються за (деталь, ефективний колір) — кожне входження ідентичної деталі й
кольору будь-де в дереві, на будь-якій глибині вкладеності, зараховується до Кіл. одного
рядка. Множення неявне й автоматичне: якщо підзбірка, що містить 2 екземпляри якоїсь панелі,
сама розміщена 3 рази у верхній збірці, рядок ВМ для цієї панелі показує Кіл. 6. Немає
окремого поля множника для встановлення вручну — все працює на основі підрахунку розміщень.

## Перш ніж почати

- Має бути відкрита збірка з принаймні одним розміщеним компонентом — див.
  [Розміщення компонентів](./placing-components.md).
- Якщо збірка використовує масиви або дзеркальні копії, переконайтеся, що вони вже
  згенеровані (див. [Масиви і дзеркало](./patterns-and-mirror.md)), щоб їхні екземпляри
  враховувалися.

## Кроки

1. Відкрийте збірку, матеріали якої хочете підсумувати.
2. На вкладці **Збірка**, у групі **ВМ**, натисніть **ВМ**.
   *Результат: смужка вкладок панелі Браузера перемикається на вкладку ВМ, показуючи один
   рядок на кожну унікальну комбінацію деталь+колір, знайдену будь-де в дереві.*
3. Клацніть рядок (поза комірками Поз. та Колір), щоб вибрати кожен екземпляр компонента
   цього рядка деталь+колір, будь-де в дереві, у дереві браузера та 3D-вигляді.
4. Двічі клацніть комірку **Поз.**, щоб редагувати її вбудовано (1–9999); двічі клацніть
   комірку **Колір**, щоб відкрити вибір кольору й перепризначити ефективний колір цього
   рядка.
5. Натисніть **Перенумерувати**, щоб перепослідовнити Поз. кожного рядка на 1..N у порядку
   рядків.
   *Результат: номери позицій скидаються до чистої послідовності; дія повністю скасовується.*
6. Натисніть **Експорт CSV** (усередині панелі ВМ, не на стрічці), щоб зберегти таблицю як
   файл `.csv`.

## Параметри

| Поле / Елемент керування | Значення |
|---|---|
| Поз. | Підпис для редагування кліком, 1–9999. Живить нумерацію Auto-Balloon (Авто-виноска) на кресленні — див. Поради нижче. |
| Арт. | Каталожний номер/артикул деталі. |
| Опис | Текст опису деталі. |
| Кіл. | Агрегована кількість цієї деталі+кольору по всьому дереву, обчислена автоматично. |
| Назва деталі | Відображувана назва деталі. |
| Колір | Редагування кліком через вибір кольору; встановлює ефективний колір, за яким групується рядок. |
| Шлях до деталі | Розташування деталі в дереві збірки. |
| Перенумерувати (стрічка) | Перепослідовнює Поз. кожного рядка на 1..N у порядку рядків; скасовується. |
| Експорт CSV (панель) | Експортує таблицю як CSV. |

## Поради та підводні камені

- **Лише CSV.** Панель ВМ експортує CSV, а не XLSX. Експорт у XLSX існує, але лише на окремій
  вкладці [Статистика](../furniture/cost-and-statistics.md).
- Заголовок CSV — точно `Item#,Part #,Description,QTY,Part Name,Color,Part Path`. Рекомендований
  шаблон імені файлу — `<assembly-name>-bom.csv`.
- **Поз. керує виносками на кресленні.** Кожен номер виноски, розміщений на аркуші креслення
  через Auto-Balloon (Авто-виноска) (див. [Анотації](../drawings/annotations.md) та
  [Таблиці отворів і специфікації](../drawings/hole-tables-and-parts-lists.md)), — це Поз. ВМ
  компонента. Натискання **Перенумерувати** також змінить номери виносок на будь-яких
  кресленнях, що посилаються на цю збірку.
- ВМ не є джерелом для пакувального листа — цей документ будується з окремої агрегації
  Розкрою, а не безпосередньо з рядків ВМ. Див. [Пакувальний лист](../manufacturing/packing-slip.md).
