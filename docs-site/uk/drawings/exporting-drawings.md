# Експорт креслень
> Експортує активний аркуш (або кожен аркуш) як DXF, PDF, PNG чи SVG для подальшого
> використання в CAM, перевірки або документації.

**Де:** Креслення ▸ Експорт · **Гарячі клавіші:** — · **Застосовується до:** креслення

## Що це робить

Панель Експорт перетворює аркуш креслення на файл, який можна передати за межі Zilventor:
`Експорт DXF` та `Експорт DXF (1:1)` — для векторного виводу, орієнтованого на обробку,
`Експорт PDF` — для перевірки/друку, `Експорт PNG` та `Експорт SVG` — для растрових/
векторних зображень, а також — щойно креслення матиме більше одного аркуша — `Експорт всіх
аркушів (DXF)` та `Експорт всіх аркушів (1:1)`, щоб експортувати все одразу як zip-архів.

## Перед початком

- `Експорт DXF`, `Експорт DXF (1:1)`, `Експорт PNG` та `Експорт SVG` потребують проекційного
  виду на **активному** аркуші — інакше вони вимкнені.
- `Експорт PDF` потребує лише проекційного виду **десь у документі** — на будь-якому аркуші,
  не обов'язково тому, який ви зараз переглядаєте.
- `Експорт всіх аркушів (DXF)` та `Експорт всіх аркушів (1:1)` з'являються у стрічці лише
  тоді, коли креслення має більше одного аркуша; в кресленні з одним аркушем ці кнопки
  взагалі не показуються.

## Кроки

### Експорт DXF / Експорт DXF (1:1)

1. Натисніть **Експорт DXF** для стандартного DXF у масштабі креслення або **Експорт
   DXF (1:1)** для справжньої геометрії розміру обробки на панелі Креслення ▸ Експорт.
2. Оберіть, куди зберегти файл, у запиті завантаження браузера.

*Результат: завантажується файл `.dxf`, що містить геометрію активного аркуша в обраному
масштабі.*

### Експорт PDF

1. Натисніть **Експорт PDF** на панелі Креслення ▸ Експорт.
2. Оберіть, куди зберегти файл.

*Результат: завантажується файл `.pdf`, що містить аркуш(і) креслення.*

### Експорт PNG / Експорт SVG

1. Натисніть **Експорт PNG** або **Експорт SVG** на панелі Креслення ▸ Експорт.
2. Оберіть, куди зберегти файл.

*Результат: завантажується растрове (`.png`) або векторне (`.svg`) зображення активного
аркуша.*

### Експорт всіх аркушів (DXF) / Експорт всіх аркушів (1:1)

1. Натисніть **Експорт всіх аркушів (DXF)** для стандартного масштабу або **Експорт всіх
   аркушів (1:1)** для масштабу обробки на панелі Креслення ▸ Експорт (видно лише тоді, коли
   креслення має більше одного аркуша).
2. Оберіть, куди зберегти файл.

*Результат: завантажується `.zip`-архів, що містить по одному DXF на кожен аркуш, в
обраному масштабі.*

## Параметри

| Поле | Значення |
|---|---|
| (немає — одноклацний експорт) | Жодна з кнопок експорту не відкриває діалог налаштувань; кожна експортує одразу, використовуючи поточний масштаб і вміст аркуша. |

## Поради та підводні камені

- **Точність розмірів у DXF** — експортер DXF записує розміри креслення як власні об'єкти
  `DIMENSION` формату R12, а не просто лінії й текст, тож анотації розмірів переносяться як
  справжні DXF-об'єкти розмірів, а не сплощена геометрія. Точна поведінка при відкритті в
  AutoCAD незалежно не перевірялася — перевірте результат, якщо це важливо для вашого
  робочого процесу.
- **Захисна перевірка `Експорт PDF` діє на весь документ, а не по-аркушно** — він доступний,
  щойно будь-який аркуш у кресленні має вид, навіть якщо аркуш, який ви зараз переглядаєте,
  його не має. Інші одноаркушеві експорти (`Експорт DXF`, `Експорт DXF (1:1)`, `Експорт PNG`,
  `Експорт SVG`) перевіряють лише активний аркуш.
- **Кнопки «Всі аркуші» не просто вимикаються на кресленні з одним аркушем — вони взагалі не
  відображаються.** Якщо ви очікуєте пакетний експорт, а бачите лише кнопки для одного
  аркуша, спершу додайте другий аркуш (див. [Аркуші](./sheets.md)).
- Вивід DXF звідси — той самий тип файлу, який споживають подальші інструменти розкладки/CAM
  — див. [DXF для виробництва](../manufacturing/manufacturing-dxf.md), якщо ви подаєте ці
  експорти в конвеєр розкладки або CAM.
