# Розміри
> Розміщує на аркуші креслення 2D-анотації розмірів (лінійні, радіальні, кутові та на основі
> баз), зчитуючи реальні виміри з геометрії, яку проєктує розміщений вид.

**Де:** Креслення ▸ Розмір · **Гарячі клавіші:** — · **Застосовується до:** креслення (розміщений вид
на активному аркуші)

## Що це робить

Панель Розмір — це група інструментів для анотування аркуша креслення розмірами: оберіть дві
точки або ребро на розміщеному виді, і інструмент розмістить лінію розміру з виміряним
значенням. Це інша функція, ніж розміри ескізу — параметричні залежності, які ви додаєте під
час ескізування в 3D-моделері (див. [Розміри](../modeling/dimensions.md)). Розміри ескізу
керують геометрією моделі; розміри креслення тут — це анотації лише для читання, призначені
для документації та виробництва, і зміна одного з них не змінює модель.

На цій панелі є дев'ять інструментів: `Лінійний (Г)`, `Лінійний (В)`, `Паралельний`,
`Радіальний`, `Діаметральний`, `Кутовий` — для вибору розмірів вручну, `Авторозмір` — для
отримання розмірів безпосередньо з вихідного ескізу, а також `Базовий` / `Координатний` — для
груп розмірів у стилі баз відліку.

## Перед початком

- Відкритий аркуш креслення з принаймні одним розміщеним видом (див.
  [Головні та проекційні види](./base-and-projected-views.md)).
- Знайте, яку геометрію ви хочете проставити розмірами — інструменти працюють через
  клацання по точках, ребрах або колах/дугах на розміщеному виді.

## Кроки

### Лінійний, паралельний, радіальний, діаметральний, кутовий

1. Натисніть потрібний інструмент на панелі Креслення ▸ Розмір — `Лінійний (Г)` для
   горизонтальної відстані, `Лінійний (В)` для вертикальної, `Паралельний` для відстані
   вздовж ребра під будь-яким кутом, `Радіальний` для радіуса кола/дуги, `Діаметральний` для
   діаметра кола/дуги або `Кутовий` для кута між двома ребрами.
2. Клацніть геометрію, яку очікує інструмент — дві точки або ребро для лінійних/паралельних
   інструментів, коло чи дугу для `Радіальний`/`Діаметральний`, два ребра для `Кутовий`.
3. Перемістіть мишу, щоб розмістити лінію розміру на потрібному відступі, потім клацніть, щоб
   її розмістити.

*Результат: на аркуші з'являється анотація розміру з виміряним значенням, прив'язана до
геометрії виду.*

### Авторозмір

1. Натисніть **Авторозмір** на панелі Креслення ▸ Розмір.
2. Клацніть вид, який хочете проставити розмірами.

*Результат: розміри генеруються автоматично з власних параметричних розмірів і параметрів
вихідного ескізу, без ручного вибору точок.*

### Базовий

1. Натисніть **Базовий** на панелі Креслення ▸ Розмір.
2. Оберіть базове (початкове) ребро на виді.
3. Оберіть по черзі кожен елемент, для якого потрібен розмір від цієї бази.

*Результат: з'являється серія розмірів, кожен з яких виміряно від того самого спільного
базового ребра.*

### Координатний

1. Натисніть **Координатний** на панелі Креслення ▸ Розмір.
2. Оберіть початкову точку або ребро, що встановлює базу відліку.
3. Оберіть кожен елемент, для якого потрібне координатне значення.

*Результат: з'являється єдина наскрізна база відліку з виноскою та значенням для кожного
вибраного елемента, виміряним від спільного початку.*

## Параметри

| Поле | Значення |
|---|---|
| (немає — керується вибором) | Ці інструменти не мають діалогу налаштувань; тип розміру, значення та розміщення повністю визначаються тим, що ви клацаєте і куди опускаєте лінію. |

## Поради та підводні камені

- **Розміри креслення проти розмірів ескізу** — не плутайте їх. Розміри ескізу
  (параметричні, задані під час моделювання) знаходяться в розділі
  [Розміри](../modeling/dimensions.md) і керують моделлю. Розміри креслення тут — це
  анотації на 2D-аркуші, які не впливають на модель.
- `Авторозмір` показує лише те, що вихідний ескіз уже має як розміри/параметри — якщо сам
  ескіз недостатньо розмірований, `Авторозмір` не вигадає значення за вас.
- `Базовий` та `Координатний` — окремі робочі процеси порівняно з шістьма ручними
  інструментами вище — сприймайте кожну послідовність клацань як власний невеликий процес, а
  не очікуйте того самого патерну «дві точки».
