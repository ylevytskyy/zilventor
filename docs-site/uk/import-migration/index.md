# Імпорт і міграція
> Як зовнішні CAD-дані — STEP, DXF, ABF-розгортка DXF та ціла бібліотека Inventor 2012 —
> потрапляють у zilventor, і що з ними можна редагувати після імпорту.

Zilventor ніколи не редагує чужі формати файлів на місці. Кожен шлях імпорту або будує
**оболонку тільки для читання** навколо геометрії, яку не може повністю зрозуміти, або
**перетворює** дані на один із власних параметричних типів елементів zilventor. Розуміння того,
який саме результат ви отримаєте, — найважливіша річ на цій сторінці.

## Два результати

| Результат | Що це означає | Шляхи імпорту, що дають цей результат |
|---|---|---|
| **Імпортована деталь тільки для читання** | Тіло(а) надходять як непрозорий елемент `kind: 'imported'`. Кнопки Add* на вкладці Model (Sketch, Extrusion, Revolve, Fillet, Hole, Shell, Sweep, масиви, опорні елементи) вимкнені з підказкою. Деталь можна розміщувати в збірках, додавати до неї залежності та вибирати її грані — але переробити її форму не можна. | STEP-файли, відкриті як нова деталь, архіви `.zip` зі STEP всередині, вся мігрована бібліотека Inventor |
| **Параметричний елемент zilventor** | Геометрія перебудовується як нативні дані zilventor — ескіз, `PanelFeature`, набір записів `BoreOp`. Повністю редагована, з підтримкою скасування та регенерації, як і все, що змодельовано вручну. | DXF, імпортований як нова деталь або в ескіз, імпорт ABF-розгортки DXF, а також імпортоване STEP-тіло, перетворене на панель заднім числом |

Два «місточки» дозволяють перейти між цими двома результатами:

- **Explode** (Розбити на збірку) перетворює багатотільну імпортовану STEP-деталь на збірку —
  по одній деталі тільки для читання на кожне тіло, зі збереженням кольорів кожного тіла — щоб
  ви могли позиціонувати, приховувати чи видаляти тіла окремо. Це не робить геометрію
  редагованою, лише розділяє її.
- **Convert to panel** (Перетворити на панель) замінює елемент тільки для читання
  однотільної імпортованої деталі на справжній `PanelFeature`, на місці, коли ви готові
  трактувати її як параметричну заготовку.

## Шляхи, якими надходить зовнішній CAD

| Сторінка | Формат | Результат |
|---|---|---|
| [STEP-файли](./step-files.md) | `.step` / `.stp`, за бажанням у zip | Деталь тільки для читання (нова деталь або вставлена як компонент збірки) |
| [DXF-файли](./dxf-files.md) | `.dxf` | Нова деталь на основі ескізу, елементи, додані до активного ескізу, або негеометрична підкладка креслення |
| [Імпорт ABF-розгортки](./abf-flatten-import.md) | `.dxf` (експорт з ABF-програми розкладки) | Одна збірка з N параметричними деталями `PanelFeature`, плюс реальні свердління там, де їх вдалося розпізнати |
| [Перетворення на панель](./convert-to-panel.md) | (крок постобробки, не формат файлу) | Перетворює вже імпортоване STEP-тіло на параметричний `PanelFeature` |
| [Міграція з Inventor](./inventor-migration.md) | Бібліотека Autodesk Inventor 2012 `.ipt`/`.iam`, через макрос експорту VBA | Пакет деталей/збірок тільки для читання з геометрією, позами, iProperties та розрахованими значеннями параметрів |
| [SolidWorks-файли](./solidworks-files.md) | `.sldprt` / `.sldasm` | Нічого напряму — інструкція спочатку конвертувати у STEP |

## Обмеження розміру

STEP- та DXF-файли, відкриті через вкладку **File**, обмежені приблизно 50 МБ; більші файли
відхиляються з попередженням про розмір ще до того, як браузер намагатиметься їх розібрати.
Дивіться кожну сторінку окремо щодо того, де це обмеження діє, а де ні.
