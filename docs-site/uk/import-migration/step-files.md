# STEP-файли
> Завантажте модель `.step`/`.stp` як деталь тільки для читання, вставте її прямо у збірку,
> або розбийте багатотільний імпорт на окремі компоненти.

**Де:** вкладка File ▸ **Open…** (нова деталь) або вкладка Assembly ▸ Component ▸ **Insert From
STEP…** (як компонент) · вкладка Model ▸ Create ▸ **Explode into Assembly** (розбити тіла) ·
**Гарячі клавіші:** — · **Застосовується до:** деталь, збірка

## Що це робить

STEP (AP2xx) — це універсальний формат zilventor для «геометрії, що прийшла звідкись іще».
Відкриття такого файлу завжди дає **деталь тільки для читання**: кожне тіло у файлі
завантажується як єдиний елемент `kind: 'imported'` — компаунд, якщо у файлі більш ніж одне
тіло — і жоден із інструментів Add* на вкладці Model (Sketch, Extrusion, Revolve, Fillet, Hole,
Shell, Sweep, масиви, опорні елементи) з нею не працює. Деталь усе одно можна розміщувати у
збірках, додавати до її граней залежності mate/flush/angle, змінювати колір і — якщо це одне
тіло — пізніше [перетворити на параметричну панель](./convert-to-panel.md).

## Перед початком

- Підготуйте файл `.step`/`.stp` (або `.zip`, що містить такий файл). Файли розміром понад
  приблизно 50 МБ одразу відхиляються з попередженням про розмір — дуже великі STEP-файли можуть
  «підвісити» вкладку браузера, тож спочатку спростіть геометрію на боці CAD-системи, якщо
  впираєтеся в це обмеження.
- Щоб вставити геометрію як **компонент** збірки, а не як окрему деталь, спочатку відкрийте або
  створіть цільову збірку.

## Кроки

### Відкрити як нову деталь

1. Вкладка **File** ▸ **Open…**.
2. Оберіть файл `.step`, `.stp` або `.zip`. У `.zip` шукається перший запис STEP усередині, і
   саме він імпортується — все інше в архіві ігнорується.
3. Дочекайтеся індикатора імпорту в рядку стану (для великих збірок це може тривати кілька
   хвилин).
4. *Результат: відкривається нова деталь з єдиним елементом `Imported (<filename>.step)` у
   дереві браузера; вигляд у вікні перегляду автоматично підганяється під модель.*

### Вставити в активну збірку

1. Відкрийте або створіть збірку, у яку потрібна геометрія.
2. Вкладка **Assembly** ▸ Component ▸ **Insert From STEP…**.
3. Оберіть файл `.step`/`.stp` або `.zip`, що його містить.
4. *Результат: у збірці з'являється новий компонент, підкріплений щойно створеною деталлю тільки
   для читання.*

### Розбити багатотільний імпорт на збірку

1. Відкрийте STEP-файл як нову деталь (див. вище), компаунд якої містить більш ніж одне тіло.
2. Вкладка **Model** ▸ Create ▸ **Explode into Assembly**. Доступно лише коли активна деталь
   містить імпортований елемент.
3. *Результат: активний документ стає новою збіркою з однією деталлю тільки для читання на
   кожне тіло; колір кожного тіла зберігається; компоненти розташовуються в нативних координатах
   STEP-файлу (тотожна поза), без повторного центрування.*

## Опції

| Поле | Значення |
|---|---|
| Фільтр вибору файлу | Приймає `.step`, `.stp` та `.zip` (у ньому шукається запис STEP) |
| Обмеження розміру | ~50 МБ, застосовується на **File ▸ Open** та шляху розпакування `.zip` перед розбором |

## Поради та підводні камені

- Підказка для тільки-для-читання на вкладці Model говорить: *«This part was imported from
  Inventor and is read-only. Re-author parametrically by creating a new part.»* — формулювання
  загальне і стосується будь-якої імпортованої геометрії, а не лише файлів з Inventor.
- **Insert From STEP…** (вкладка Assembly) наразі не має жодного обмеження розміру в коді, на
  відміну від **File ▸ Open** та імпорту DXF — дуже великі файли, вставлені цим шляхом, не
  отримають того ж попередження заздалегідь.
- Explode з'являється лише коли активний документ — це деталь з імпортованим елементом; він
  недоступний для збірок чи деталей, побудованих нативно.
- Розбиття не робить геометрію параметричною — кожне отримане тіло все одно залишається деталлю
  тільки для читання. Скористайтеся [Перетворенням на панель](./convert-to-panel.md) пізніше для
  будь-якого однотільного тіла, яке потрібно редагувати.
- STEP-файл, який не вдалося розібрати (пошкоджена геометрія, непідтримувані сутності),
  показується як діалог помилки «Open failed» із повідомленням від ядра.
