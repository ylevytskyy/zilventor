# Імпорт ABF-розгортки
> Перетворіть «розгорнутий» (flatten) експорт DXF з ПЗ розкладки/маркування ABF на справжню
> збірку zilventor із параметричних панелей — зі свердліннями, відновленими як редаговані
> елементи, а не плоскі лінії.

**Де:** вкладка File ▸ **Import ABF flatten DXF…** · **Гарячі клавіші:** — · **Застосовується до:**
збірка (створює нову)

## Що це робить

Розгорнуті DXF-експорти в стилі ABF пакують кожну панель партії корпусів на одне креслення, по
одному контуру на панель, зі свердлінням/фрезеруванням, позначеним колами на певних шарах, і
ідентичністю панелі, закодованою в атрибутах блоку. Цей імпортер реконструює цю конвенцію: він
групує записи DXF за матеріалом і товщиною, дозволяє підтвердити відповідність
матеріалу/товщини, а потім будує одну справжню **збірку** zilventor, що містить одну деталь
**`PanelFeature`** на кожну виявлену панель — кожна повноцінна, редагована, розташована у своєму
початку координат, а не тупий контур.

Кола, які можна впевнено розмістити на широкій грані панелі, стають справжніми записами
`BoreOp` (з розміщенням за UV на основі кута, з найкращим можливим зіставленням до відомого
типу фурнітури — полицетримач, чашка петлі, конфірмат, нагель, мінікс, ніжка-регулятор — за
діаметром). Кола, які не вдається впевнено розпізнати — крайові записи (`DSIDE`) або записи
грані з невідомою глибиною (`DEPTHF`), чи діаметри, що не збігаються з жодним відомим типом
фурнітури — переходять у прості довідкові кола на панелі, щоб нічого з вихідного файлу не
загубилося непомітно.

## Перед початком

- Підготуйте експорт `.dxf` ABF-розгортки (обмеження розміру ~50 МБ, як і для інших імпортів
  DXF).
- Приблизно знайте, до якого матеріалу має мапитися кожна виявлена група — діалог підтвердження
  заздалегідь заповнює товщину з файлу, але матеріал обираєте ви.

## Кроки

1. Вкладка **File** ▸ **Import ABF flatten DXF…**.
2. Оберіть файл `.dxf`. Кириличні назви панелей, вбудовані в атрибути блоків файлу, зберігаються
   як є.
3. Відкривається діалог **Import ABF flatten DXF** з одним рядком на кожну виявлену групу
   матеріалу (формат токена `<MATERIAL>_THICKNESS_<mm>`):
   - Оберіть **Material** з активного реєстру матеріалів для кожної групи.
   - Підтвердьте або скоригуйте заздалегідь заповнену **Thickness (mm)**.
4. Натисніть **Import** (або **Cancel**, щоб перервати — нічого не буде створено).
5. *Результат: нова збірка стає активним документом, містить одну деталь `PanelFeature` на
   кожну виявлену панель, усі розміщені в початку координат збірки. Рядок стану повідомляє
   кількість імпортованих панелей, кількість свердлінь, відновлених як справжні `BoreOp`, і
   скільки кіл потрапило як лише довідкова геометрія; будь-які нерегулярні контури згадуються в
   тому ж повідомленні.*

## Опції

| Поле | Значення |
|---|---|
| Група матеріалу (мітка рядка) | Автоматично виявлений токен `<MATERIAL>_THICKNESS_<mm>` з DXF — лише для читання |
| Material | До якого матеріалу zilventor призначаються панелі цієї групи |
| Thickness (mm) | Товщина панелі для цієї групи; заздалегідь заповнена з токена DXF, редагована |

## Поради та підводні камені

- Це **нова збірка**, а не імпорт у поточно активний документ — якщо була відкрита інша збірка,
  вона замінюється активним документом (усе одно доступна через скасування).
- Уся операція — один крок зі скасуванням: Ctrl+Z прибирає збірку і видаляє кожен файл деталі,
  який вона записала.
- Панелі розміщуються в початку координат збірки, а не в позиції компонування, яку передбачає
  вихідний DXF — переставте їх після імпорту, якщо потрібне конкретне розташування.
- Розміщення свердлінь — найкраще можливе для всього, крім чашки петлі Ø35 (єдиний діаметр,
  однозначний серед типів фурнітури zilventor). Перевіряйте імпортовані свердління за вихідним
  кресленням, перш ніж покладатися на них у виробництві.
- Дивіться [Схему шарів ABF](../manufacturing/abf-layer-scheme.md) щодо конвенції
  шарів/іменування, яку розбирає цей імпортер.
