# Клавіатурні скорочення

> Кожне клавіатурне скорочення, яке розпізнає застосунок, згруповане за режимом застосування — плюс два скорочення, задокументовані тут як непрацюючі, щоб ви не витрачали на них час.

Усі скорочення нечутливі до регістру та ігноруються, коли фокус перебуває в текстовому полі введення чи textarea (тож введення значення в поле діалогу ніколи не викликає інструмент). Яка таблиця застосовується, залежить від того, що активне: **режим ескізу** під час редагування ескізу, **режим збірки** під час активного документа збірки, та **режим деталі/моделі** в інших випадках (документ деталі або збірка без активного ескізу).

## Режим ескізу (без модифікатора)

Активний лише під час редагування ескізу.

| Клавіша | Дія |
|---|---|
| L | Лінія |
| R | Прямокутник |
| C | Коло |
| A | Дуга |
| S | Сплайн |
| N | Залежність збігання |
| H | Залежність горизонтальності |
| V | Залежність вертикальності |
| P | Залежність паралельності |
| E | Залежність перпендикулярності |
| T | Залежність дотику |
| Q | Залежність рівності |
| Y | Залежність симетрії |
| D | Розмір |
| Esc | Скасувати активний інструмент і повернутися до режиму «Вибрати» |
| Enter | Підтвердити поточний крок активного інструмента |

## Режим деталі/моделі (без модифікатора)

Активний завжди, коли не редагується ескіз (документ деталі або збірка без відкритого ескізу).

| Клавіша | Дія |
|---|---|
| R | Обертання |
| F | Спряження |
| K | Фаска |
| S | Оболонка |
| L | Лінійний масив |
| M | Дзеркало |
| H | Отвір |
| W | Зсув по траєкторії |

## Модифікатори (будь-який режим, крім ескізу)

| Скорочення | Дія |
|---|---|
| Ctrl/Cmd+Shift+P | Робоча площина |
| Ctrl/Cmd+Shift+A | Робоча вісь |
| Ctrl/Cmd+Shift+W | Робоча точка |

Робоча точка прив'язана до Shift+W (а не до простого W), тому що просте `W` вже зайняте під Зсув по траєкторії у режимі деталі/моделі — свідоме відхилення від стандартної карти клавіш Autodesk Inventor.

## Режим збірки (без модифікатора)

Активний лише поки активний документ збірки.

| Клавіша | Дія | Працює? |
|---|---|---|
| P | Розмістити компонент | Так |
| M | Зіставлення | **Ні — див. відому проблему нижче** |
| F | Врівень | **Ні — див. відому проблему нижче** |
| N | Кут | Так |
| I | Вставити | Так |
| G | Перемкнути закріплення (для вибраного компонента) | Так, якщо компонент вибрано |
| Ctrl/Cmd+Shift+S | Перемкнути блокування залежності (для вибраної залежності) | Так, якщо залежність вибрано |

## Глобальні (будь-який режим)

| Скорочення | Дія |
|---|---|
| F7 | Перемкнути панель параметрів |
| Ctrl/Cmd+Z | Скасувати |
| Ctrl/Cmd+Y **або** Ctrl/Cmd+Shift+Z | Повторити |

## Відомі проблеми

- **Кнопки «До екрану (F)» та «Додому» на вкладці «Вигляд» нічого не роблять.** Обидві кнопки рендеряться без жодного обробника кліку — натискання на них не має ефекту. У застосунку немає жодної робочої команди «підігнати під екран» чи «скинути до домашнього вигляду», доступної через будь-яку кнопку чи клавішу. В'юпорт автоматично один раз перекадровує модель одразу після відкриття документа або перемикання на нього, але нічого не дозволяє повторно викликати це згодом.
- **Просте натискання F не підганяє вигляд — воно відкриває Спряження**, бо режим деталі/моделі перехоплює клавішу F першим. «(F)» в назві кнопки «До екрану» застаріле — воно не відображає реального прив'язаного скорочення.
- **У режимі збірки просте M (Зіставлення) і просте F (Врівень) ніколи не спрацьовують**, хоча обробник скорочень збірки їх визначає. Обробники режиму деталі/моделі для Дзеркала (M) та Спряження (F) виконуються першими й «з'їдають» натискання клавіші раніше, ніж його побачить обробник збірки, тож ці два скорочення збірки є мертвим кодом. Використовуйте кнопки стрічки для Зіставлення та Врівень замість клавіатурного скорочення. Кут (N), Вставити (I), Перемкнути закріплення (G) та Ctrl/Cmd+Shift+S працюють як очікується.
