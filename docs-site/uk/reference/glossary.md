# Глосарій

> Терміни меблевого CAD і специфічні для застосунку, визначені так, як їх насправді використовує цей застосунок — а не лише в загальному столярному значенні.

### ABF

Стороннє розширення для SketchUp («ABF Extension»), яке використовують для ЧПУ-орієнтованого виробництва корпусних меблів; сама абревіатура ніде не розшифровується навіть у документації плагіна. Експорт Manufacturing DXF у Zilventor пропонує схему шарів «ABF» (поряд зі «Native» — «Стандартна»), яка іменує шари відповідно до конвенцій ABF, для цехів, чий подальший CAM-процес очікує вихідні дані у стилі ABF. Див. [Схема шарів ABF](../manufacturing/abf-layer-scheme.md).

### ВМ (BOM, Bill of Materials)

Агрегований перелік деталей для збірки: екземпляри компонентів групуються за деталлю та ефективним кольором, кожна група отримує стабільний номер позиції, а ВМ фіксує кількість, назву деталі та (якщо задано) номер деталі й опис. Див. [Відомість матеріалів](../assemblies/bill-of-materials.md).

### Конфірмат (Confirmat)

Міжпанельний гвинтовий з'єднувач. Zilventor свердлить його парою отворів: наскрізний отвір Ø7мм на лицьовій стороні однієї панелі та отвір Ø5мм у крайку суміжної панелі (глибина = довжина гвинта 50мм мінус товщина панелі з лицьової сторони). Див. [Генерування присадки корпусу](../drilling-prisadka/generate-carcass-boring.md).

### Шкант (Dowel)

Просте клейове з'єднання на шкантах. Свердлиться як гніздо Ø8мм × 12мм у панелі з лицьової сторони та гніздо Ø8мм × 13мм (обмежене товщиною плити) у крайку суміжної панелі. Див. [Генерування присадки корпусу](../drilling-prisadka/generate-carcass-boring.md).

### DXF (Drawing Exchange Format)

Векторний 2D-формат обміну даними компанії AutoCAD. Використовується в застосунку для експорту креслень, експорту виробництва/розкладки та імпорту DXF. Див. [Формати експорту](./export-formats.md) та [Файли DXF](../import-migration/dxf-files.md).

### Кромкування (Edge-banding)

Стрічковий або смуговий матеріал, що наклеюється на крайку розкроєної панелі, щоб приховати основу. Моделюється окремо для кожної кромки (спереду/ззаду/ліворуч/праворуч), кожна зі своїм матеріалом і товщиною; габаритний (розкрійний) розмір панелі додає товщини обклеєних кромок до її чистого (готового) розміру. Див. [Панелі](../furniture/panels.md).

### Словник граней (Top / Bottom / Front / Back / Left / Right)

Шість іменованих граней панелі. **Top** (Зверху) та **Bottom** (Знизу) — дві великі грані, нормаль яких проходить уздовж осі товщини панелі. **Front** (Спереду), **Back** (Ззаду), **Left** (Ліворуч) та **Right** (Праворуч) — вузькі крайкові грані, не ширші за товщину плити, які не мають власного плаского 2D/DXF-представлення. Свердління, пази та інші елементи обробки завжди розміщуються відносно однієї з цих шести іменованих граней. Див. [Свердління / Присадка](../drilling-prisadka/index.md).

### Напрямок волокна (Grain direction)

Параметр панелі — довжина, ширина або відсутній — який обмежує, в якій орієнтації панель дозволено розкладати. Панель із заблокованим напрямом волокна пробується лише в орієнтації, що відповідає її волокну; якщо вона не поміщається так, але *помістилася б* повернутою, розкладка виключає її з причиною «напрям волокна заблокований — перевищує аркуш» замість загальної «панель перевищує аркуш», щоб можна було відрізнити ці дві причини відмови. Див. [Розкладка](../manufacturing/nesting.md).

### Гільйотинна розкладка (Guillotine nest)

Стиль різу алгоритму розкладки: кожен розподіл простору аркуша утворює два підпрямокутники, кожен з яких охоплює всю решту ширини або висоти, тож кожен результуючий різ проходить прямо, від краю до краю, — саме такий різ здатна виконати панельна пилка за один прохід. L-подібні або часткові розрізи ніколи не утворюються. Див. [Розкладка](../manufacturing/nesting.md).

### iPart / Конфігурація (Configuration)

Іменований збережений набір значень параметрів деталі — аналог iParts в Autodesk Inventor. Активація конфігурації масово встановлює параметри деталі відповідно до цього збереженого набору, дозволяючи одному визначенню деталі породжувати кілька іменованих варіантів. Див. [Параметри та конфігурації](../concepts/parameters-and-configurations.md).

### Ширина пропилу (Kerf)

Ширина пилкового диска або фрези. Додається як проміжок між сусідніми панелями під час розкладки, щоб макет враховував матеріал, справді втрачений на різ, а не лише контакт «панель до панелі». Див. [Розкладка](../manufacturing/nesting.md).

### Мінікс (Minifix)

Ексцентриковий стяжний з'єднувач. Свердлиться як отвір Ø15мм під корпус ексцентрика плюс поперечний отвір Ø8мм в ексцентрик на лицьовій стороні однієї панелі, та окремий отвір Ø8мм під стяжний гвинт у крайку суміжної панелі. Див. [Генерування присадки корпусу](../drilling-prisadka/generate-carcass-boring.md).

### OPFS

Origin Private File System — приватне, ізольоване локальне файлове сховище браузера, яке Zilventor використовує як бекенд для кожного файлу проєкту, SKU фурнітури та шаблону протягом сесії. Ніщо не залишає межі браузера, доки ви явно не експортуєте або не збережете дані деінде. Див. [Збереження та сесії](../concepts/saving-and-sessions.md).

### Накладка (Overlay)

Спосіб монтажу фасаду дверей чи шухляди відносно прорізу шафи. Повна (Full) та напівнакладна (Half) накладки виступають фасадом над лицем шафи; вкладна (Inset) розташовує фасад врівень усередині прорізу. Тип накладки також змінює відступ чашки петлі. Див. [Двері](../furniture/doors.md).

### Припуск (Oversize)

Додаткова допуска довжини/ширини на різ, що додається понад чистий (готовий) розмір панелі перед розкладкою — наприклад, щоб залишити припуск на обробку після механічної доводки. Це відрізняється від габаритного розміру, що додається [кромкуванням](#кромкування-edge-banding). Див. [Розкладка](../manufacturing/nesting.md) та [Розкрій](../furniture/cut-list.md).

### Присадка (Prisadka)

Загальний термін — і назва вкладки стрічки — для інструментів свердління фурнітури та обробки: свердління з'єднувачів корпусу, полицетримачів Система-32, чашок петель, пазів і дадо, замкових пазів, шипових з'єднань, свердління під ручки та регульованих ніжок. Див. [Свердління / Присадка](../drilling-prisadka/index.md).

### Залишок (Remnant)

Єдиний найбільший вільний прямокутник (щонайменше 100мм з кожної сторони), що залишився на розкладеному аркуші. Zilventor позначає його під час експорту, щоб його можна було відстежувати як придатну для повторного використання заготовку, але дрібніші обрізки система взагалі не відстежує — лише один найбільший залишок на аркуш. Див. [Розкладка](../manufacturing/nesting.md).

### Зазор (Reveal)

Зазор, що лишається навколо крайки накладних дверей відносно прорізу шафи (типово 2мм). Вкладні двері натомість використовують еквівалентне значення «зазор вкладної» (clearance), а проріз із двома дверима використовує окремий «центральний зазор» (типово 3мм) для проміжку між двома дверима. Див. [Двері](../furniture/doors.md).

### STEP (Standard for the Exchange of Product Data)

3D-формат обміну ISO 10303. Використовується для імпорту та експорту твердотільної геометрії через ядро застосунку на основі OCCT. Див. [Формати експорту](./export-formats.md) та [Файли STEP](../import-migration/step-files.md).

### Система-32 (System-32)

Стандартна для цеху лінійна розкладка свердлінь Ø5мм із кроком 32мм: глухі отвори свердлять у внутрішній стороні бокової панелі шафи, щоб регульовані полицетримачі могли встановлюватися з кроком 32мм у будь-якій позиції. Див. [Полицетримачі Система-32](../drilling-prisadka/system-32-shelf-pins.md).

### Цоколь (Toekick)

Заглиблена цокольна панель у нижній передній частині нижньої шафи. Навісні та верхні шафи мають нульову висоту цоколя. Регульовані ніжки зазвичай встановлюються за цоколем, поза полем зору. Див. [Регульовані ніжки](../drilling-prisadka/leg-levelers.md) та [Шафи](../furniture/cabinets.md).
