# Формати експорту

> Кожен експорт, який може виконати застосунок, — що він містить, у якому форматі опиняється та де саме натиснути, щоб його викликати.

## Меню «Файл»

| Експорт | Формат | Де |
|---|---|---|
| Експорт зображення | `.png` | Вкладка «Файл» ▸ **Експорт зображення** (має опцію фону «Прозорий»). Знімок поточного вьюпорта. |
| Експорт STEP | `.step` | Вкладка «Файл» ▸ **Експорт STEP**. Документи деталей експортуються напряму; збірки рекурсивно розгортають кожен вкладений компонент в один файл. Вимкнено для креслень. |
| Експорт STL | `.stl` (бінарний) | Вкладка «Файл» ▸ **Експорт STL**. Та сама логіка розгортання деталі/збірки, що й для STEP. Вимкнено для креслень. |

## Експорт креслення (.zidw)

Де: панель **Вкладка «Креслення» ▸ Експорт**.

| Експорт | Формат | Область | Примітки |
|---|---|---|---|
| Експорт PDF | `.pdf` | Усі аркуші | Один багатосторінковий PDF для всього креслення. |
| Експорт DXF | `.dxf` | Лише активний аркуш | Масштабовано відповідно до масштабу виду аркуша; включає розміри, штрихування, таблиці отворів, основний напис і вихідну геометрію. |
| Експорт DXF (1:1) | `.dxf` (суфікс `-1to1.dxf`) | Лише активний аркуш | Лише геометрія, у справжніх міліметрах моделі — ігнорує масштаб виду аркуша. Види перекомпоновуються впритул один до одного. Без розмірів, штрихування, таблиць отворів чи основного напису. Це експорт «розміру обробки», відмінний від звичайного експорту DXF вище. |
| Експорт PNG | `.png` | Лише активний аркуш | |
| Експорт SVG | `.svg` | Лише активний аркуш | |
| Експорт всіх аркушів (DXF) | `.zip` (по одному `.dxf` на аркуш) | Усі аркуші | Показується лише коли креслення має більше одного аркуша. |
| Експорт всіх аркушів (1:1) | `.zip` (суфікс `-1to1.zip`) | Усі аркуші з проекційним видом | Показується лише коли креслення має більше одного аркуша. |

Немає пакетного експорту «всі аркуші» для PNG чи SVG — лише DXF має варіант zip для кількох аркушів, оскільки PDF за своєю суттю вже охоплює всі аркуші.

## Меблі ▸ Присадка (свердління) — експорт

Де: панель **Вкладка «Меблі» ▸ Присадка**.

| Експорт | Формат | Примітки |
|---|---|---|
| Експорт CSV (присадка) | `.csv` | Усі свердління агреговані рекурсивно по всій збірці. |
| Експорт DXF (присадка) | `.dxf` | Той самий агрегований набір свердлінь; перед експортом показує будь-які проблеми попередньої перевірки як спливні сповіщення. |
| Експорт DXF (Виробництво) | `.zip`, або один `.dxf` у комбінованому режимі | Один DXF на панель, згруповані в підпапки за матеріалом усередині zip, плюс супутній файл `machining.csv` у корені zip. Два перемикачі поруч із кнопкою керують цим: **Режим експорту DXF** («Папки за матеріалом» проти «Один спільний файл») та **Схема шарів** («Стандартна» проти «ABF»). Комбінований режим також видає другий файл `machining.csv` для завантаження, коли будь-яка присадка/паз/шип-гніздо несе дані інструмента, похідні від пресету. |

## Розкрій

Де: панель **Вкладка «Меблі» ▸ Розкрій**, або вкладка **Розкрій** у панелі браузера.

| Експорт | Формат | Примітки |
|---|---|---|
| Експорт CSV | `.csv` | Та сама команда з обох місць. Версія в панелі браузера додатково включає рядки фурнітури та ВМ з'єднувачів; версія з панелі стрічки включає лише рядки з'єднувачів, без рядків фурнітури. |

## Розкладка (компонування аркуша)

Де: панель **Вкладка «Меблі» ▸ Розкладка**, плюс кнопка PNG для кожного аркуша у вкладці **Розкладка** панелі браузера.

| Експорт | Формат | Область | Примітки |
|---|---|---|---|
| Експорт PDF | `.pdf` | Усі аркуші розкладки | Один документ. |
| Експорт DXF (Розкладка) | `.zip` за матеріалом, або один комбінований `.dxf` | Усі аркуші розкладки | Використовує той самий перемикач «Папки за матеріалом / Один спільний файл», що й DXF Виробництва вище. |
| Експорт PNG | `.png` (`nest-{materialId}-{sheetIndex}.png`) | По одному аркушу за раз | Кнопка знаходиться на панелі кожного аркуша у вкладці «Розкладка» панелі браузера, а не на стрічці «Меблі». Немає пакетного «експортувати всі PNG розкладки». |

## Етикетки

Де: панель **Вкладка «Меблі» ▸ Розкладка** ▸ **Експорт етикеток (PDF)**.

| Експорт | Формат | Примітки |
|---|---|---|
| Експорт етикеток (PDF) | `.pdf` | Одна цехова етикетка на кожну фізичну копію панелі з розкрою. Суміжні елементи керування: перемикач шаблону Розширений/Компактний, два довільних рядки заголовка та вибір пресету заголовка. |

## Пакувальний лист

Де: панель **Вкладка «Меблі» ▸ Виробництво**, або вкладка **Виробництво** панелі браузера.

| Експорт | Формат | Примітки |
|---|---|---|
| Пакувальний лист (PDF) | `.pdf` | Та сама команда з обох місць. Відображає актуальний статус виготовлено/не виготовлено, який відстежується звіркою через сканування QR-кодів. |

## ВМ

Де: лише вкладка **ВМ** у панелі браузера — на стрічці «Меблі» немає кнопки експорту ВМ.

| Експорт | Формат | Примітки |
|---|---|---|
| Експорт CSV | `.csv` (`{assembly}-bom.csv`) | Агрегує рекурсивно в усі розміщені підзбірки. |

## Статистика / звіт витрат

Де: панель **Вкладка «Меблі» ▸ Статистика**, або вкладка **Статистика** панелі браузера.

| Експорт | Формат | Примітки |
|---|---|---|
| Експорт CSV | `.csv` | |
| Експорт XLSX | `.xlsx` | Один аркуш на категорію витрат (Фурнітура, З'єднувачі, Кромка, Погонний матеріал, Панелі), кожен із рядком «Підсумок», плюс підсумковий аркуш (Summary) із проміжними підсумками кожного розділу, Загальною сумою та кількістю рядків без ціни. |
