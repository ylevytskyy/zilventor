# Довідник

> Довідковий матеріал — клавіатурні скорочення, формати файлів, формати експорту та термінологія — на випадок, коли ви вже знаєте, що вам потрібно, і хочете просто знайти точну відповідь.

На відміну від решти посібника, ці сторінки не організовані навколо задачі. Переходьте одразу до потрібної таблиці:

- [Клавіатурні скорочення](./keyboard-shortcuts.md) — повна карта клавіш для ескізу, деталі, збірки та глобальних команд, зокрема два скорочення, які наразі не роблять того, що обіцяє їхня назва.
- [Формати файлів](./file-formats.md) — чотири власні формати (`.zipt`, `.ziasm`, `.zidw`, `.zitpl`), поточна версія маніфесту та як міграція застосовується під час відкриття старішого файлу.
- [Формати експорту](./export-formats.md) — кожен експорт, який може виконати застосунок, згрупований за місцем виклику.
- [Глосарій](./glossary.md) — терміни меблевого CAD та специфічні для застосунку, від «ВМ» до «Присадки» і «цоколя».
