# Експорт даних присадки
> Два швидкі звіти присадки для всієї збірки — плоский CSV та 2D DXF-розкладка — для швидкого
> перегляду кожного отвору без запуску повного виробничого експорту.

**Де:** Меблі ▸ Присадка ▸ **Експорт CSV (присадка)** / **Експорт DXF (присадка)** ·
**Гарячі клавіші:** — · **Застосовується до:** збірка

## Що це робить

Ці дві кнопки експортують **кожен отвір активної збірки** (рекурсивно заходячи у вкладені
підзбірки) у двох різних форматах:

- **Експорт CSV (присадка)** записує один рядок на отвір — плоский звіт обробки, який можна
  відкрити в електронній таблиці або подати у власне оснащення.
- **Експорт DXF (присадка)** малює один прямокутник на панель (використовуючи її реальні довжину
  × ширину, якщо вони відомі) з текстовою міткою та колом для кожного з її отворів, розкладені
  поруч в одному DXF — швидка візуальна карта присадки, а не виробниче креслення.

Обидва читають з того самого агрегованого результату присадки, тож кількість отворів у них завжди
збігається.

## Перед тим, як почати

- В активній збірці вже мають бути отвори — див.
  [Генерування присадки корпусу](./generate-carcass-boring.md),
  [Ручки та кнопки](./handles-and-pulls.md) або [Регульовані ніжки](./leg-levelers.md).
- Обидві кнопки неактивні, доки не відкрита збірка.

## Кроки

1. На вкладці Меблі, панель Присадка, натисніть **Експорт CSV (присадка)** або
   **Експорт DXF (присадка)**.
2. Якщо ваш браузер підтримує нативний вибір файлу збереження, оберіть, куди зберегти; інакше
   файл завантажується автоматично як `<assembly-name>-boring.csv` або
   `<assembly-name>-boring.dxf`.

*Результат: єдиний файл, що охоплює кожен отвір збірки, готовий до відкриття або передачі.*

## Параметри

Для жодного з експортів немає діалогу — кожен виконується одним клацанням. Стовпці CSV:

| Стовпець | Значення |
|---|---|
| Panel | Назва деталі панелі. |
| Length / Width / Thickness | Реальні розміри панелі в mm (порожньо, якщо недоступні). |
| Tag | Внутрішній ідентифікатор отвору. |
| Face | З якої грані свердлиться отвір (`Top`, `Bottom`, `Front`, `Back`, `Left`, `Right`). |
| X / Y | Позиція U/V отвору в системі координат грані панелі, в mm. |
| Ø | Діаметр отвору в mm. |
| Depth | Глибина різання в mm, або `THROUGH` для наскрізного отвору. |
| Type | Тип з'єднувача (напр. `handleScrew`, `legLeveler`, `shelfPin`, …). |

DXF групує отвори в шари з назвою `D<diameter>_<depth or THROUGH>` — суто за розміром, тож усі
наскрізні отвори Ø5 потрапляють в один шар незалежно від їхнього призначення.

## Поради та підводні камені

- **Ці два експорти не несуть CAM-метадані пресетів обробки.** Номер інструменту, швидкість
  шпинделя та власна назва цільового шару [пресету обробки](./machining-presets.md) **не**
  з'являються в CSV чи DXF присадки — стовпець `Type` у CSV показує тип з'єднувача, а шар DXF
  завжди має назву `D<dia>_<depth>`, похідну від розміру. Якщо потрібні відновлювані з файлу
  номер інструменту/швидкість, або отвори, розкладені на іменований шар пресету, скористайтеся
  натомість **Експорт DXF (Виробництво)** — див.
  [Виробничий DXF](../manufacturing/manufacturing-dxf.md) і
  [CAM-метадані](../manufacturing/cam-metadata.md). Цей поканальний (per-panel) експорт також
  підтримує [схему шарів ABF](../manufacturing/abf-layer-scheme.md), розкладку та цехові
  етикетки — більш повний робочий процес, ніж ці два швидкі звіти.
- **Експорт DXF (присадка)** показує будь-які проблеми попередньої перевірки (панель без назви,
  матеріалу чи розв'язної геометрії) у вигляді спливних повідомлень на екрані перед записом
  файлу — прочитайте їх; проблемна панель усе одно включається, лише, можливо, із запасними
  розмірами.
- Якщо реальні довжина/ширина панелі невідомі, DXF повертається до прямокутника, розмір якого
  визначається за позиціями самих отворів плюс невеликий запас, тож контур може не точно
  відповідати фізичній панелі.
