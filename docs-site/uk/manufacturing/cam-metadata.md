# CAM-метадані
> Номер інструменту та швидкість шпинделя, зняті знімком з пресета обробки на присадку чи паз, вбудовані у DXF для виробництва як метадані, що можна прочитати оператору ЧПК.

**Де:** Меблі ▸ Присадка ▸ **Експорт DXF (Виробництво)** (метадані додаються автоматично, це не окремий перемикач) · **Гарячі клавіші:** — · **Застосовується до:** присадки/пазів, створених або відредагованих з пресета обробки

## Що це робить

CAM-метадані — це не налаштування, яке ви вмикаєте, а побічний результат
використання [пресетів обробки](../drilling-prisadka/machining-presets.md).
Коли пресет зі значенням **Номера інструменту** та/або **Швидкості**
застосовується до присадки чи паза, ці два значення знімаються знімком на
цей елемент згідно з
ADR 0001 —
подальше редагування чи видалення пресета ніколи не змінює елемент, до
якого його вже було застосовано.

Щоразу, коли такий елемент включається в експорт
[DXF для виробництва](./manufacturing-dxf.md), його номер інструменту та
швидкість записуються в DXF як XDATA під зареєстрованим ідентифікатором
застосунку `ZILVENTOR`: груповий код `1000` (`TOOL_NUMBER`), за яким іде
`1070` (ціле число) для номера інструменту, та/або груповий код `1000`
(`SPEED`), за яким іде `1040` (число з плаваючою комою) для швидкості
шпинделя. Присадка без жодного зі значень не видає XDATA взагалі — її
DXF-елемент побайтово ідентичний присадці без CAM-метаданих. У режимі
експорту **Один спільний файл** ті самі номер інструменту та швидкість
також з'являються як колонки `toolNumber`/`speed` у супутньому файлі
`machining.csv`.

**У цьому конвеєрі немає жодного поля швидкості подачі.** Існують лише
номер інструменту та швидкість шпинделя.

Ці метадані мають довідковий характер: zilventor не керує верстатом ЧПК
безпосередньо, а нативні CAM-формати (CIX, MPR, XNC) не реалізовані. DXF
для виробництва (і його супутній `machining.csv`) — єдиний доступний
вихідний файл, з якого оператор ЧПК чи розкрійний сервіс може прочитати
підказки щодо інструменту/швидкості.

## Перш ніж почати

- Присадка чи паз мають бути створені або відредаговані з використанням
  [пресета обробки](../drilling-prisadka/machining-presets.md), у якого
  задано Номер інструменту та/або Швидкість.
- Ви експортуєте через [DXF для виробництва](./manufacturing-dxf.md) — не
  існує окремого шляху експорту лише для CAM-метаданих.

## Кроки

1. У **Пресетах обробки** встановіть **Номер інструменту** та/або
   **Швидкість** на пресеті(ах), які використовують ваші присадка/пази —
   див. [Пресети обробки](../drilling-prisadka/machining-presets.md).
2. Застосуйте пресет до присадки/пазів, яким це потрібно.
3. Запустіть [Експорт DXF (Виробництво)](./manufacturing-dxf.md) як
   зазвичай — для включення метаданих не потрібен жодний додатковий
   перемикач.
4. Якщо ви використали режим **Один спільний файл** і хоча б один
   експортований елемент несе CAM-метадані, також заберіть супутній файл
   `machining.csv`, записаний поруч із DXF.

*Результат: будь-яка експортована присадка/паз, що має номер інструменту чи
швидкість, несе їх як XDATA з APPID `ZILVENTOR` у DXF, а в об'єднаному
режимі — ще й як рядок у `machining.csv`.*

## Параметри

| Поле | Значення |
|---|---|
| Номер інструменту (на пресеті) | Цілочисельний номер інструменту ЧПК, записаний як DXF XDATA груповий код `1070` під ключем `TOOL_NUMBER`, і як колонка `toolNumber` у `machining.csv`. |
| Швидкість (на пресеті) | Швидкість шпинделя в об/хв, записана як DXF XDATA груповий код `1040` під ключем `SPEED`, і як колонка `speed` у `machining.csv`. |

## Поради та підводні камені

- **Не кожен експорт це несе.** Звичайні звіти
  [Експорт CSV (присадка) / Експорт DXF (присадка)](../drilling-prisadka/exporting-boring-data.md)
  ніколи не включають номер інструменту, швидкість чи будь-яку XDATA — шари
  DXF присадки завжди мають назву, похідну від розміру, `D<dia>_<depth>`, а
  CSV присадки взагалі не має колонок інструменту/швидкості. Лише
  [DXF для виробництва](./manufacturing-dxf.md) (і його супутній
  `machining.csv`) несе CAM-метадані; див.
  [Відомі обмеження](../troubleshooting/known-limitations.md) і
  [Експорт даних присадки](../drilling-prisadka/exporting-boring-data.md)
  для повного порівняння.
- **Це довідкові метадані, а не керування ЧПК.** zilventor ніколи не керує
  верстатом безпосередньо, і немає експорту CIX/MPR/XNC — XDATA в DXF
  призначені для читання будь-яким CAM-програмним забезпеченням чи
  оператором, що обробляє файл.
- Оскільки інструмент/швидкість знімаються знімком у момент застосування,
  дві присадки, що використали той самий пресет, можуть отримати різні
  метадані, якщо пресет був відредагований між їхніми застосуваннями —
  перевіряйте саму присадку, а не пресет, якщо число виглядає підозріло.
- Присадка без номера інструменту й без швидкості не видає жодного блоку
  XDATA для цієї присадки — це очікувана поведінка, а не помилка; не
  очікуйте порожнього/нульового запису XDATA.
