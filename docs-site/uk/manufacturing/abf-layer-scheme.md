# Схема шарів ABF
> Альтернативна схема іменування шарів для DXF для виробництва, що відповідає граматиці шарів стороннього плагіна розкрійного сервісу ABF, для цехів, що працюють за цим процесом.

**Де:** Меблі ▸ Присадка ▸ **Експорт DXF (Виробництво)** ▸ Схема шарів: **ABF** · **Гарячі клавіші:** — · **Застосовується до:** експорту DXF для виробництва

## Що це робить

«ABF» — це назва бренду, а не абревіатура; вона позначає конкретний
сторонній плагін розкрійного сервісу, чиї назви шарів DXF слідують відомій
угоді. Коли **Схема шарів** встановлена на **ABF** (див.
[DXF для виробництва](./manufacturing-dxf.md)), zilventor називає шар DXF
кожного елемента відповідно до цієї угоди замість власних стандартних назв:

| Елемент | Назва шару ABF | Приклад |
|---|---|---|
| Контур панелі | `ABF_cuttingLines` | `ABF_cuttingLines` |
| Присадка грані (Top/Bottom), пресет має SKU | `DEPTH<depth>-ARTICLE<sku>` | `DEPTH15-ARTICLE$12345` |
| Присадка грані (Top/Bottom), пресет без SKU | `DEPTH<depth>` | `DEPTH15` |
| Присадка кромки (Front/Back/Left/Right) | `ABF-DSIDE-<diameter>` | `ABF-DSIDE-5` |

SKU, що використовується для суфікса `ARTICLE` присадки грані, береться з
[пресета обробки](../drilling-prisadka/machining-presets.md), застосованого
до цієї присадки. Присадки кромок ніколи не отримують суфікс артикула — SKU
для них ігнорується.

## Перш ніж почати

- «Експорт DXF (Виробництво)» має бути доступним (активна збірка зі
  згенерованою присадкою/пазами) — див.
  [DXF для виробництва](./manufacturing-dxf.md).
- Якщо потрібні суфікси `ARTICLE` на присадках граней, відповідний
  [пресет обробки](../drilling-prisadka/machining-presets.md) повинен мати
  задане SKU.

## Кроки

1. На вкладці «Меблі», в панелі «Присадка», встановіть **Схему шарів** на
   **ABF**.
2. Встановіть **Режим експорту DXF** як завжди (Папки за матеріалом / Один
   спільний файл).
3. Натисніть **Експорт DXF (Виробництво)**.

*Результат: експортовані DXF використовують назви шарів у стилі ABF замість
власних стандартних назв zilventor для кожного елемента, що має
відповідність ABF.*

## Параметри

| Поле | Значення |
|---|---|
| Схема шарів — ABF | Перемикає іменування шарів DXF для виробництва на угоду ABF, показану вище. |
| Схема шарів — Стандартна | Власні назви шарів zilventor — див. [DXF для виробництва](./manufacturing-dxf.md). |

## Кириличні SKU

SKU пресета може містити кириличні символи (українські чи російські). Перш
ніж потрапити в назву шару `ARTICLE` присадки грані, він санітизується:
кириличні літери транслітеруються в латиницю (за таблицею романізації, що
зберігає регістр першої транслітерованої літери), потім кожен символ поза
`[A-Za-z0-9_$-]` замінюється на `_`, повторювані підкреслення схлопуються в
одне, а початкові й кінцеві підкреслення обрізаються. Символ `$` навмисно
дозволений, оскільки реальні SKU ABF мають префікс `$`. Точна
транслітерована форма конкретного кириличного SKU залежить від цієї
таблиці романізації — перевіряйте експортовану назву шару безпосередньо,
якщо потрібно знати її точно.

## Поради та підводні камені

- **Присадка `throughAll` (наскрізна на всю глибину) ніколи не отримує
  назву шару ABF.** У цій схемі немає угоди для «наскрізної», тож наскрізна
  присадка мовчки повертається до своєї стандартної назви шару, навіть коли
  решта експорту використовує назви ABF. Якщо ви шукаєте у DXF шари в стилі
  ABF і присадка відсутня, перевірте, чи вона не наскрізна.
- **Це підмножина повної граматики ABF**, а не повна реалізація. Реальні
  сторонні файли експорту ABF також використовують сімейства шарів на
  кшталт `D<n>-DEPTHF-$<sku>` та шар `ABF_Label`, які експортер zilventor
  не створює — вони належать до сторони імпорту, доступної лише для
  читання (див. [Імпорт ABF розгортки](../import-migration/abf-flatten-import.md)),
  а не до цього експортера.
- Перемикання Схеми шарів не змінює, які панелі експортуються чи як вони
  дедуплікуються — лише те, як позначено шар кожного елемента. Див.
  [DXF для виробництва](./manufacturing-dxf.md) для цього механізму.
- Явна цільова назва шару
  [пресета обробки](../drilling-prisadka/machining-presets.md) завжди
  перекриває схему ABF для цього елемента, так само як вона перекриває
  Стандартну схему.
