# Виробництво
Огляд розділу «Виробництво»: що він охоплює та з чого почати.

Коли шафа чи збірка змодельована й для неї згенеровано присадку/пази, розділ
«Виробництво» доводить її до готового виробу меблів. Конвеєр виконується
приблизно в такому порядку:

1. **Розкрій** — панелі, розміри та матеріали збірки агрегуються
   (див. [Розкрій](../furniture/cut-list.md)).
2. **Розкладка** — панелі укладаються на аркуші матеріалу, окремий макет для
   кожного матеріалу, щоб знати, скільки аркушів купити та як їх розкроїти
   ([Розкладка](./nesting.md)), з можливістю підправити розміщення потім
   ([Редагування розкладки](./editing-the-nest.md)).
3. **Виробничі файли** — файли для цеху, що фактично виходять з програми:
   CNC-готовий DXF по кожній панелі ([DXF для виробництва](./manufacturing-dxf.md)),
   опційно з іменуванням шарів, сумісним зі сторонньою системою
   ([Схема шарів ABF](./abf-layer-scheme.md)), і з відновлюваними метаданими
   інструменту/швидкості ([CAM-метадані](./cam-metadata.md)); етикетки для
   друку з QR-кодами ([Етикетки та QR](./labels-and-qr.md)); розбивка вартості
   матеріалів/фурнітури ([Звіт про вартість](./cost-report.md)); і пакувальний
   лист для готового замовлення ([Пакувальний лист](./packing-slip.md)).
4. **Різання** — DXF (а для цехів, що працюють з CAM, — вбудовані метадані
   інструменту/швидкості) передається розкрійному сервісу чи оператору
   верстата ЧПК, який повертає розкроєні панелі.
5. **Звірка виробництва** — коли панелі повертаються, їхні QR-коди
   скануються, щоб звірити фізичну купу деталей з розкроєм
   ([Звірка виробництва](./production-reconciliation.md)).

## Сторінки цього розділу

- [DXF для виробництва](./manufacturing-dxf.md) — дедуплікований DXF-експорт
  по кожній панелі для розкрою/ЧПК.
- [Розкладка](./nesting.md) — розкласти розкрій на аркушах.
- [Редагування розкладки](./editing-the-nest.md) — вручну підправити готовий
  макет.
- [Етикетки та QR](./labels-and-qr.md) — етикетки для друку по кожній панелі.
- [Схема шарів ABF](./abf-layer-scheme.md) — іменування шарів, сумісне зі
  сторонньою системою, для DXF для виробництва.
- [CAM-метадані](./cam-metadata.md) — номер інструменту/швидкість шпинделя,
  вбудовані у DXF для виробництва.
- [Звіт про вартість](./cost-report.md) — розбивка вартості матеріалів/фурнітури.
- [Пакувальний лист](./packing-slip.md) — зведення замовлення для друку.
- [Звірка виробництва](./production-reconciliation.md) — звірка сканування
  проти розкрою.
