# Масиви та дзеркало
> Повторює елемент вздовж лінії (Лінійний масив) або віддзеркалює його відносно площини (Дзеркало) в межах однієї деталі.

**Де:** Model ▸ Pattern · **Гарячі клавіші:** Лінійний масив **L** · Дзеркало **M** ·
**Застосовується до:** деталь

## Що це робить

Лінійний масив і Дзеркало повторюють наявний елемент поточної деталі — Лінійний масив копіює
його задану кількість разів із фіксованим кроком вздовж осі X/Y/Z, а Дзеркало віддзеркалює його
відносно однієї з трьох головних площин. Обидва працюють на рівні **елемента деталі**,
повторюючи елемент у межах дерева елементів однієї деталі.

Це відрізняється від еквівалентів на рівні збірки, які повторюють або дзеркально відображають
цілі **екземпляри компонентів** усередині збірки, а не елементи в межах деталі — див.
[Масиви та дзеркало збірки](../assemblies/patterns-and-mirror.md), якщо потрібно повторити
компонент, а не елемент.

Дзеркало відкривається як центроване модальне вікно; Лінійний масив закріплюється у верхньому
правому куті екрана, залишаючи 3D-вікно перегляду інтерактивним під ним.

## Перед тим як почати

- Деталь потребує наявного суцільного тіла з принаймні одним елементом, придатним для масиву.
- Кожна кнопка тут вимкнена з підказкою *"Цю деталь імпортовано з Inventor, і вона доступна
  лише для читання. Створіть нову деталь, щоб редагувати її параметрично."*, коли активна
  деталь була імпортована (наприклад, зі STEP).

## Кроки

### Лінійний масив

1. Натисніть **Лінійний масив (L)** або клавішу **L**.
2. Оберіть **Джерело** зі спадного списку елементів, придатних для масиву.
3. Оберіть **Вісь** (**X / Y / Z**).
4. Задайте **Крок** і **Кількість**.
5. Натисніть **OK**.

*Результат: вихідний елемент повторюється вздовж обраної осі, і елемент "Лінійний масив"
додається до дерева елементів деталі.*

### Дзеркало

1. Натисніть **Дзеркало (M)** або клавішу **M**.
2. Оберіть **Джерело** зі спадного списку елементів, придатних для масиву.
3. Оберіть **Площину** (**YZ / XZ / XY**).
4. Натисніть **OK**.

*Результат: дзеркальна копія вихідного елемента додається відносно обраної площини, і елемент
"Дзеркало" додається до дерева елементів деталі.*

## Параметри

### Лінійний масив

| Поле | Значення | За замовчуванням |
|---|---|---|
| Джерело | Спадний список елементів деталі, придатних для масиву | перший елемент, придатний для масиву |
| Вісь | Перемикач **X / Y / Z** | X |
| Крок | Відстань між екземплярами; приймає вирази | `20` |
| Кількість | Ціле число, має бути 2–200 | `3` |

### Дзеркало

| Поле | Значення | За замовчуванням |
|---|---|---|
| Джерело | Спадний список елементів деталі, придатних для масиву | перший елемент |
| Площина | Перемикач **YZ / XZ / XY** | YZ |

## Поради та підводні камені

- Діалог Дзеркала прямо пояснює математику площин: "YZ — дзеркало по x=0; XZ — по y=0; XY — по
  z=0" — використовуйте це як швидку довідку замість того, щоб вгадувати, яка площина
  відповідає якій осі.
- **Кількість** обмежена діапазоном 2–200 — не можна створити масив з одним екземпляром (це
  просто був би вихідний елемент) чи необмежений.
- Жоден із діалогів не має кнопки Застосувати/попередній перегляд — лише Скасувати/OK — тож
  ретельно перевіряйте Джерело та Вісь/Площину перед підтвердженням.
- Не плутайте інструменти цієї сторінки з Pattern/Mirror на рівні збірки, які повторюють цілі
  компоненти в межах збірки, а не елемент в межах однієї деталі — див.
  [Масиви та дзеркало збірки](../assemblies/patterns-and-mirror.md).
