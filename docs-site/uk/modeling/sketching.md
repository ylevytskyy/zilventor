# Ескізування
> Малює 2D-профіль — лінії, прямокутники, кола, дуги та сплайни — на основі якого будуються залежності, розміри та 3D-елементи.

**Де:** вкладка Sketch ▸ панель Sketch ▸ **2D Ескіз** (щоб увійти) / **Завершити ескіз** (щоб
вийти) · **Гарячі клавіші:** — · **Застосовується до:** деталь

## Що це робить

Ескіз — це плоский 2D-малюнок, який пізніше стає вхідними даними для 3D-елемента, такого як
Extrude чи Revolve. Вкладка Sketch у Zilventor надає невеликий набір інструментів малювання
(лінія, прямокутник, коло, дуга, сплайн), перемикач конструктивної геометрії для довідкових
об'єктів і два обхідні шляхи для отримання геометрії без малювання від руки: діалог числового
прямокутника та імпорт DXF.

## Перед тим як почати

- Відкрийте деталь. Ескізування вимкнено для [імпортованих деталей](./index.md) — вони доступні
  лише для читання.

## Кроки

### Увійти в режим ескізу та вийти з нього

1. Натисніть **2D Ескіз**. Якщо деталь уже має елемент ескізу, буде використано останній
   існуючий; інакше створюється новий ескіз на початковій площині XY.
2. Малюйте та редагуйте геометрію за допомогою інструментів нижче.
3. Натисніть **Завершити ескіз**, щоб вийти з режиму ескізу та повернутися до стану Ready.

*Результат: елемент ескізу додається (або оновлюється) у дереві елементів деталі.*

### Інструменти малювання

1. Натисніть **Вибрати**, щоб обирати й переміщувати наявну геометрію без малювання.
2. Натисніть **Лінія** (комбінація клавіш **L**) і клацайте, щоб розмістити кінцеві точки
   кожного відрізка.
3. Натисніть **Прямокутник** (комбінація клавіш **R**) і клацніть по двох протилежних кутах.
4. Натисніть **Коло** (комбінація клавіш **C**) і клацніть по центральній точці, а потім по
   точці радіуса.
5. Натисніть **Дуга** (комбінація клавіш **A**) і клацніть по точках, що визначають дугу.
6. Натисніть **Сплайн** (комбінація клавіш **S**) і клацайте по кожній контрольній точці по
   черзі.

*Результат: нові об'єкти з'являються в активному ескізі, готові до накладання залежностей і
розмірів.*

### Конструктивна геометрія

1. Натисніть **Конструктивна**, щоб увімкнути конструктивний режим.
2. Малюйте будь-яким із інструментів вище — об'єкти, намальовані під час увімкненого
   перемикача, позначаються як конструктивна геометрія (лише довідкова, не є частиною профілю,
   який споживатиме елемент).
3. Натисніть **Конструктивна** ще раз, щоб повернутися до малювання звичайної (профільної)
   геометрії.

*Результат: наступні намальовані об'єкти позначаються як конструктивна геометрія, доки ви не
вимкнете перемикач.*

### Числовий прямокутник

Використовуйте це, коли потрібен точний прямокутник без перетягування кутів на екрані.

1. Натисніть **Числовий прямокутник…** — доступний завжди, навіть поза режимом ескізу.
2. Заповніть поля діалогу (див. Параметри нижче).
3. Натисніть **OK**.

*Результат: створюється абсолютно новий елемент ескізу з одним прямокутником, розмір якого
відповідає введеним значенням.*

### Імпорт DXF

1. З активним ескізом відкрийте панель Import і натисніть **Імпорт DXF…**.
2. Оберіть файл `.dxf` у діалозі вибору файлу.

*Результат: геометрія DXF додається безпосередньо в поточний активний ескіз.*

## Параметри

**Діалог числового прямокутника** ("Прямокутник (дві кутові точки)"):

| Поле | Значення | За замовчуванням |
|---|---|---|
| x1 | X-координата першого кута | 0 |
| y1 | Y-координата першого кута | 0 |
| x2 | X-координата протилежного кута | 100 |
| y2 | Y-координата протилежного кута | 200 |

Після натискання **OK** дві кутові точки нормалізуються у прямокутник ширина/висота.

## Поради та підводні камені

- Підпис кнопки **Конструктивна** містить жорстко закодовану підказку "(X)", але жодна
  комбінація клавіш `X` насправді ніде в застосунку не підключена — натискайте кнопку, а не
  шукайте клавішу.
- **Числовий прямокутник…** не додає геометрію в поточний відкритий ескіз — він завжди створює
  окремий, абсолютно новий елемент ескізу, що містить лише цей один прямокутник.
- **Імпорт DXF…** доступний лише під час активного ескізу і імпортує геометрію безпосередньо в
  нього — на відміну від числового прямокутника, він не створює власного нового елемента
  ескізу.
- Не плутайте 2D-інструменти вкладки Sketch **Offset**, **Fillet**, **Chamfer**, **Trim**,
  **Extend** та **Project** з 3D-інструментами **Fillet**/**Chamfer** на вкладці Model
  ([Зміна елементів](./modify-features.md)) — назви перетинаються навмисно (вони виконують
  аналогічні дії), але версії вкладки Sketch працюють лише з 2D-геометрією ескізу.
