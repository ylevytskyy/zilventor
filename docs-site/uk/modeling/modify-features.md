# Зміна елементів
> Закруглює, зрізає, робить порожнистим і пробиває отвори в наявному суцільному тілі за допомогою Спряження, Фаски, Оболонки та Отвору.

**Де:** Model ▸ Modify · **Гарячі клавіші:** Спряження **F** · Фаска **K** · Оболонка **S** ·
Отвір **H** · **Застосовується до:** деталь

## Що це робить

Панель Modify містить чотири інструменти, що змінюють форму вже наявного суцільного тіла,
замість того щоб створювати його з ескізу: **Спряження** закруглює ребра, **Фаска** зрізає
ребра, **Оболонка** робить тіло порожнистим, перетворюючи його на оболонку сталої товщини
стінки, а **Отвір** прорізає отвір (простий, з зенківкою або з конічним заглибленням) наскрізь
або в тіло.

Усі чотири відкривають діалог, закріплений у верхньому правому куті екрана, залишаючи 3D-вікно
перегляду інтерактивним під ним. Там, де в діалозі є кнопка **Вибрати** або **Додати**,
спочатку натисніть її, щоб увімкнути режим вибору у вікні перегляду, а потім клацніть по
ребру/грані/контуру в 3D-вигляді — список вибору в діалозі оновлюється в реальному часі, поки
діалог залишається відкритим.

## Перед тим як почати

- Деталь потребує наявного суцільного тіла — інакше жодному з чотирьох інструментів немає з
  чим працювати.
- Кожна кнопка тут вимкнена з підказкою *"Цю деталь імпортовано з Inventor, і вона доступна
  лише для читання. Створіть нову деталь, щоб редагувати її параметрично."*, коли активна
  деталь була імпортована (наприклад, зі STEP).

## Кроки

### Спряження

1. Натисніть **Спряження (F)** або клавішу **F**.
2. Оберіть **Режим**: **Постійне** або **Змінне**.
3. Оберіть режим вибору (**Ребро / Контур / Елемент / Усі спряження / Усі заокруглення**) і
   виберіть ребра у вікні перегляду, щоб додати їх на вкладку **Ребра**.
4. Задайте **Радіус** (режим Постійне) або перейдіть на вкладку **Змінне**, щоб задати
   **Початковий радіус**/**Кінцевий радіус** для кожного ребра (лише режим Змінне).
5. Якщо у вершині сходяться рівно три спряжені ребра, за потреби задайте її значення на вкладці
   **Відступи**.
6. Натисніть **Застосувати** для попереднього перегляду, потім **OK**.

*Результат: вибрані ребра закруглюються, і елемент "Спряження" додається до дерева елементів
деталі.*

### Фаска

1. Натисніть **Фаска (K)** або клавішу **K**.
2. Оберіть режим вибору (**Ребро / Контур / Елемент**) і виберіть ребра у вікні перегляду.
3. Задайте **Відстань**.
4. Натисніть **Застосувати** для попереднього перегляду, потім **OK**.

*Результат: вибрані ребра зрізаються на однакову відстань, і елемент "Фаска" додається до
дерева елементів деталі.*

### Оболонка

1. Натисніть **Оболонка (S)** або клавішу **S**.
2. Діалог відкривається вже заповненим прапорцем для кожної грані тіла; позначте грані, які
   потрібно видалити (відкрити), або натисніть **Вибрати**, щоб додати грань, клацнувши по ній
   у вікні перегляду.
3. Задайте **Товщину**.
4. Натисніть **OK**.

*Результат: тіло робиться порожнистим у вигляді оболонки сталої товщини, відкритої на
позначених гранях, і елемент "Оболонка" додається до дерева елементів деталі.*

### Отвір

1. Натисніть **Отвір (H)** або клавішу **H**.
2. Оберіть **Розміщення**: **З ескізу**, **Лінійне** або **Концентричне**, і виберіть
   ескіз/грань/ребра, які він запитує.
3. Оберіть **Профіль**: **Простий**, **Зенківка** або **Зенкування під потай**, і задайте поля
   діаметра, які він показує.
4. Оберіть **Завершення** і задайте його **Глибину** або **Вибрати цільову грань** за потреби.
5. Натисніть **OK**.

*Результат: отвір прорізається в тілі, і елемент "Отвір" додається до дерева елементів деталі.*

## Параметри

### Спряження

| Поле | Значення | За замовчуванням |
|---|---|---|
| Радіус | Радіус спряження (вкладка Ребра); приймає вирази | `1` |
| Початковий радіус / Кінцевий радіус | Для кожної пари ребер, лише вкладка Змінне, коли режим = Змінне | — |
| Відступи | Значення відступу для кожного ребра, показується лише для вершин, де сходяться рівно 3 спряжені ребра | — |

### Фаска

| Поле | Значення | За замовчуванням |
|---|---|---|
| Відстань | Єдина рівна відстань фаски; приймає вирази | `1` |

### Оболонка

| Поле | Значення | За замовчуванням |
|---|---|---|
| Грані для видалення | Список прапорців усіх поточних граней тіла (заповнений заздалегідь), плюс кнопка Вибрати, щоб додати грань, клацнувши по ній у вікні перегляду | нічого не позначено |
| Товщина | Товщина стінки — від'ємне значення робить порожнистим усередину (чаша), додатне — збільшує назовні | `-1` |

### Отвір

| Поле | Значення | За замовчуванням |
|---|---|---|
| Розміщення | **З ескізу / Лінійне / Концентричне** — визначає, які кнопки вибору з'являються | — |
| Діаметр | Діаметр отвору (усі профілі) | `5` |
| Діаметр зенківки / Глибина зенківки | Лише профіль Зенківка | `10` / `3` |
| Діаметр конічного заглиблення / Кут конічного заглиблення | Лише профіль Зенкування під потай | `10` / `82` |
| Завершення | **Відстань / Наскрізь / До грані / До наступного** | Наскрізь |
| Глибина | Показується, коли Завершення = Відстань | `10` |

## Поради та підводні камені

- Перемикач режиму вибору **Спряження** включає **Усі спряження** та **Усі заокруглення**,
  чого **Фаска** не пропонує — Фаска має лише Ребро / Контур / Елемент.
- **Фаска працює лише з однаковою відстанню.** Поля кута немає, і режиму з двома відстанями
  немає.
- Діалог **Оболонки** — єдиний з чотирьох, чий список вибору заповнений заздалегідь (кожною
  гранню тіла, без позначки), а не починається порожнім — Спряження, Фаска й Отвір усі
  починаються без жодного вибору, доки ви не виберете щось самі.
- В Оболонки й Отвору немає кнопки **Застосувати** (лише Скасувати/OK); у Спряження й Фаски —
  є.
- **Кнопка "До екрану (F)" на вкладці Вигляд наразі не працює** — до неї взагалі не підключено
  обробник кліку, тож вона ніколи не вписує вигляд. Клавіша **F**, яку можна очікувати для
  вписування вигляду, натомість відкриває діалог **Спряження**. Якщо вписування вигляду не
  відбувається при натисканні F — саме тому; користуйтеся іншими елементами керування
  кадруванням у вікні перегляду.
