# Витягування, обертання і зсув по траєкторії
> Перетворює замкнутий 2D-профіль ескізу на 3D-тіло: виштовхуючи його прямо (Витягування), обертаючи навколо осі (Обертання) або протягуючи вздовж траєкторії (Зсув по траєкторії).

**Де:** Model ▸ Create · **Гарячі клавіші:** Витягування — · Обертання **R** · Зсув по
траєкторії **W** · **Застосовується до:** деталь

## Що це робить

Витягування, Обертання і Зсув по траєкторії — це три інструменти створення тіл на основі
профілю. Кожен бере замкнутий профіль ескізу і перетворює його на тіло: Витягування виштовхує
його на фіксовану відстань в одному напрямку, Обертання обертає його навколо робочої осі чи
лінії ескізу на заданий кут, а Зсув по траєкторії протягує його вздовж окремої кривої-траєкторії.
Усі три можуть створювати абсолютно нове тіло або поєднуватися з наявним (Об'єднати/Відняти).

Кожен інструмент відкриває діалог. Витягування відкривається як центроване модальне вікно;
Обертання і Зсув по траєкторії закріплюються у верхньому правому куті екрана, залишаючи 3D-вікно
перегляду інтерактивним під ними. Там, де в діалозі є кнопка **Вибрати**, спочатку натисніть її,
щоб увімкнути режим вибору у вікні перегляду, а потім клацніть по ребру, грані чи прив'язці в
3D-вигляді — поле діалогу оновлюється в реальному часі.

## Перед тим як почати

- Деталь потребує принаймні одного ескізу з одним замкнутим контуром профілю.
- Інструмент вимкнено, якщо в деталі немає ескізу або якщо деталь була імпортована (наприклад,
  зі STEP) і доступна лише для читання — підказка говорить: *"Цю деталь імпортовано з Inventor,
  і вона доступна лише для читання. Створіть нову деталь, щоб редагувати її параметрично."*

## Кроки

### Витягування

1. Намалюйте і замкніть профіль ескізу.
2. Натисніть **Витягування** на панелі Model ▸ Create.
3. Задайте **Відстань** і оберіть **Операцію**.
4. Натисніть **OK**.

*Результат: з'являється нове тіло (або тіло, об'єднане/відняте з наявним), і елемент
"Витягування" додається до дерева елементів деталі.*

### Обертання

1. Натисніть **Обертання (R)** або клавішу **R**.
2. Натисніть **Вибрати** біля поля **Профіль**, а потім клацніть по замкнутому профілю ескізу у
   вікні перегляду.
3. Натисніть **Вибрати** біля поля **Вісь**, а потім клацніть по робочій осі або лінії ескізу,
   навколо якої обертати.
4. Задайте **Кут** і **Напрямок**, оберіть **Операцію**.
5. За бажанням натисніть **Застосувати**, щоб побачити результат без закриття діалогу.
6. Натисніть **OK**.

*Результат: обернене тіло додається до деталі, і елемент "Обертання" з'являється у дереві
елементів.*

### Зсув по траєкторії

1. Натисніть **Зсув по траєкторії** або клавішу **W**.
2. Натисніть **Вибрати профіль**, а потім клацніть по замкнутому профілю ескізу для зсуву.
3. Натисніть **Вибрати траєкторію**, а потім клацніть по кривій траєкторії, вздовж якої
   виконувати зсув.
4. Оберіть **Орієнтацію**; якщо **Направляюча**, натисніть **Вибрати направляючу** і виберіть
   криву направляючої.
5. Оберіть **Операцію**.
6. Натисніть **OK**.

*Результат: зсунуте по траєкторії тіло додається до деталі, і елемент "Зсув по траєкторії"
з'являється у дереві елементів.*

## Параметри

### Витягування

| Поле | Значення | За замовчуванням |
|---|---|---|
| Відстань | Відстань витягування; має бути позитивним числом | `18` |
| Операція | Перемикач **Нова / Об'єднати / Відняти** (Об'єднати/Відняти вимкнено, доки в деталі немає тіла) | Об'єднати, якщо тіло існує, інакше Нова |

### Обертання

| Поле | Значення | За замовчуванням |
|---|---|---|
| Профіль | Кнопка Вибрати/Змінити; показує id ескізу та кількість замкнутих контурів після вибору | немає |
| Вісь | Кнопка Вибрати/Змінити | немає |
| Назва | Назва параметра, згенерована для кута | `angle0` |
| Кут | Поле виразу (у градусах); перевіряється в реальному часі, некоректні вирази блокують Застосувати/OK | `360` |
| Напрямок | Перемикач **Перевернутий / Симетричний / Звичайний** | Звичайний |
| Операція | Перемикач **Нова / Об'єднати / Відняти** (Об'єднати/Відняти залежить від наявності тіла) | Об'єднати/Нова залежно від наявності тіла |

### Зсув по траєкторії

| Поле | Значення | За замовчуванням |
|---|---|---|
| Профіль | Кнопка "Вибрати профіль" | немає |
| Траєкторія | Кнопка "Вибрати траєкторію" | немає |
| Орієнтація | Перемикач **Траєкторія / Паралельно / Направляюча** | Траєкторія |
| Направляюча | Кнопка "Вибрати направляючу", показується лише коли Орієнтація = Направляюча | немає |
| Операція | Перемикач **Нова / Об'єднати / Відняти** (Об'єднати/Відняти залежить від наявного тіла) | Нова |

## Поради та підводні камені

- **У Витягування немає вибору профілю.** Воно завжди застосовується до останнього доданого
  елемента ескізу в дереві елементів деталі — а не до того ескізу, який ви клацнули останнім.
  Якщо в деталі кілька ескізів, перевірте, який з них найновіший, перш ніж витягувати, інакше
  ви витягнете не той профіль.
- У Витягування немає параметра **Напрямок** — воно завжди витягує в одному фіксованому
  напрямку вперед. Якщо потрібен інший напрямок, малюйте ескіз на протилежній грані або
  переверніть площину ескізу.
- Варіанти **Операції** у Витягуванні — лише Нова / Об'єднати / Відняти — варіанта "Перетин"
  немає.
- Обертання — єдиний з трьох інструментів із живою кнопкою **Застосувати**, тож можна
  попередньо переглянути обертання без закриття діалогу; Витягування і Зсув по траєкторії
  пропонують лише Скасувати/OK.
- Ядро перевіряє ескіз перед запуском будь-якого з цих інструментів і повідомляє про конкретні
  помилки: порожній ескіз повідомляє *"Ескіз порожній — витягування неможливе. Спочатку
  намалюйте замкнутий профіль."*; незамкнутий профіль повідомляє *"Ескіз не замкнутий —
  витягування неможливе. Перевірте, що всі кінцеві точки з'єднані."*; ескіз із більш ніж одним
  замкнутим контуром повідомляє *"Ескіз має кілька замкнутих контурів — витягування неможливе.
  Об'єднайте або видаліть контури, щоб залишився рівно один."* Обертання додає власне
  повідомлення з урахуванням осі: *"Замкнутого профілю в ескізі не знайдено (без урахування
  осі)."*
