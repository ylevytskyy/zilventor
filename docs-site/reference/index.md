# Reference
> Lookup material — keyboard shortcuts, file formats, export formats, and terminology — for when you know what you want and just need the exact answer.

Unlike the rest of the manual, these pages aren't organized around a task. Jump straight to the table you need:

- [Keyboard Shortcuts](./keyboard-shortcuts.md) — the complete key map for sketch, part, assembly, and global commands, including two shortcuts that currently don't do what their label suggests.
- [File Formats](./file-formats.md) — the four native formats (`.zipt`, `.ziasm`, `.zidw`, `.zitpl`), the current manifest version, and how opening an older file migrates it.
- [Export Formats](./export-formats.md) — every export the app can produce, grouped by where you trigger it.
- [Glossary](./glossary.md) — furniture-CAD and app-specific terms, from "BOM" to "Присадка" to "toekick."
