# Troubleshooting
> Known issues, browser quirks, and answers to the questions that come up most —
> read this before filing a bug.

Zilventor is under active development, and a few rough edges are known and
tracked rather than hidden. This section is split into three pages:

- **[Known Limitations](./known-limitations.md)** — features that are
  intentionally partial, dead UI controls, and gaps that are tracked but not
  yet closed. Check here first if something seems broken but isn't a crash.
- **[Browser Issues](./browser-issues.md)** — Chromium-only features, storage
  requirements, and what the kernel-offline / solver-crashed banners mean.
- **[FAQ](./faq.md)** — short answers to recurring questions about saving,
  session restore, disabled buttons, and file compatibility.

If your problem isn't covered by any of these, it's likely a genuine bug —
note the exact steps, the console error (if any), and the file's format
version before reporting it.
